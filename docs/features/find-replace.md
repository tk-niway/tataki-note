# 文章の検索と置換

パネルに書いている文章の中を、検索バーで探したり、置き換えたりできます。VSCode の検索ウィジェットと同じ操作で、一致のハイライト・件数の表示・正規表現・大文字と小文字の保持などが使えます。探せるのは、今パネルに出ている文章だけです。下書きや履歴を探すには [下書きと履歴](drafts-and-history.md) の `⌘K` を使います。

## 検索バーを出す

| 操作 | 結果 |
|---|---|
| `⌘F`(Command + F) | 検索バーを出します。文字を選んでいるときは、その文字が検索語に入ります(選んでいなければ、残っている検索語のままです)。すでに出ているときは、検索欄に移ります |
| `⌥⌘F`(Option + Command + F) | 置換の欄まで開いた検索バーを出します |
| タイトルバーの虫眼鏡のアイコン(「検索と置換(⌘F)」) | 検索バーを出します |

- 検索バーはタイトルバーの下に出て、入力欄が押し下げられます。パネルはその高さだけ下へ伸びます(画面の下に収まらない分は上へずれます)。閉じると、元の位置と高さに戻ります。
- 検索欄の左の `>` を押すと、置換の欄が開き閉じします。
- `esc` か、バーの右端の ×(「閉じる(esc)」)で閉じます。閉じても、パネルは閉じません。
- 検索語・置換語・オプションは、パネルを閉じて開き直しても、別の下書きや履歴を開いても残ります。TatakiNote を終了すると初期の状態に戻ります。

## 探す

検索欄(「検索」)に打つと、一致する文字がすべてハイライトされ、今の一致が強調されます。右に「3/12」のように、今の一致の番号と一致の数が出ます。一致が無いときは「結果なし」です。一致が 19999 件を超えるときは「19999+」と出ます。

| キー | 動き |
|---|---|
| `↩` / `⌘G` | 次の一致へ。最後の次は最初に戻ります |
| `⇧↩` / `⇧⌘G` | 前の一致へ |

- バーの ↑ ↓ のボタン(「前の一致(⇧↩)」「次の一致(↩)」)でも移れます。
- 日本語入力で変換中の `↩` は、変換の確定になります。
- 全角と半角、ひらがなとカタカナは区別します。

### オプション

検索欄の右にある3つのボタンで切り替えます。オンのボタンは色が付きます。置換の欄の右には、「AB」のボタンがあります。

| ボタン | キー | 動き |
|---|---|---|
| 「Aa」(大文字と小文字を区別する) | `⌥⌘C` | 大文字と小文字を区別して探します |
| 「ab」(単語単位で探す) | `⌥⌘W` | 単語として独立している一致だけを探します。日本語の文字は単語の区切りになりません |
| 「.*」(正規表現を使う) | `⌥⌘R` | 検索語を正規表現として使います。`^` と `$` は行の頭と終わりに、`\n` は改行に一致します。`.` は改行に一致しません |
| 「AB」(大文字と小文字を保持する) | `⌥⌘P` | 置換するとき、一致した文字の大文字・小文字の形を置換語に移します |

- 正規表現が正しくないときは、検索欄が赤い枠になり、「正規表現が正しくありません」と出ます。
- 改行を含む検索語は、検索欄では「↵」で表示されます。改行をまたいで探せます。

## 置き換える

置換の欄(「置換」)に置換語を打ち、ボタンかキーで置き換えます。

| 操作 | キー | 動き |
|---|---|---|
| 「置換」(次を置換) | 置換欄で `↩`、どこでも `⇧⌘1` | 今の一致を置き換えます |
| 「すべて置換」 | 置換欄で `⌘↩`、どこでも `⌥⌘↩` | すべての一致を置き換えます |

- 一致が無いあいだは、置換のボタンは押せません。
- 置き換えは、入力欄で `⌘Z` で取り消せます。
- 正規表現がオンのときは、置換語の `$1`〜`$99`(括弧で囲んだ部分)・`$&` と `$0`(一致した全体)・`$$`(`$` そのもの)・`\n`(改行)・`\t`(タブ)・`\\`(`\`)が使えます。オフのときは、置換語をそのまま入れます。
- 大文字と小文字を保持がオンのときは、たとえば `Foo` を `bar` に置き換えると `Bar`、`FOO` なら `BAR` になります。

## 検索欄・置換欄のキー

| キー | 動き |
|---|---|
| `⌃↩`(Control + Return) | 欄に改行を入れます |
| `Tab` / `⇧Tab` | 検索欄 → 置換欄 → 入力欄の順に移ります / 置換欄から検索欄に戻ります |
| `⌘↓`(Command + ↓) | 入力欄に戻ります |
| `esc` | 検索バーを閉じます |
| `⌘X` / `⌘C` / `⌘V` / `⌘A` / `⌘Z` / `⇧⌘Z` | 欄の中の切り取り・コピー・貼り付け・すべて選択・取り消し・やり直し。`⌘Z` は欄に打った文字だけを戻し、入力欄の文章は戻しません |

- 検索欄・置換欄の中の `⌘↩` と `⇧⌘↩` は、確定(挿入・送信)になりません。
- キーの一覧は、設定の「ホットキーとキー操作」→「パネルの中で使えるキー」の「検索と置換」でも見られます([ショートカットキーの一覧](settings.md#ショートカットキーの一覧))。

## 知っておくこと

- 検索のキー(`⌘F`・`⌥⌘F`・`⌘G`・`⇧⌘G`・`⌥⌘C`・`⌥⌘W`・`⌥⌘R`・`⌥⌘P`・`⇧⌘1`・`⌥⌘↩`)は、確定+挿入キー・確定+送信キーに登録できません。すでに登録してあったときは、起動したときに初期値に戻ります([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。
- 選択した範囲の中だけを探す、検索語の履歴、一致をすべて選ぶ、といった VSCode の操作はありません。
