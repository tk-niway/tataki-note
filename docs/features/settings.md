# 設定ウィンドウ

設定ウィンドウでは、パネルを開くホットキー、確定のキー、パネルを出す位置、自動表示、テーマ、ログイン時に起動、メニューバーのアイコンの表示のほか、パネルの文字・透明度・既定の大きさ・帯の項目を変えられます。バージョンとアクセシビリティの許可の状態も確かめられます。
変えた値はその場で保存され、TatakiNote を起動し直さなくても次の操作から効きます。

## 設定ウィンドウを開く

1. メニューバーの TatakiNote のアイコンをクリックします。
2. 「設定」を選びます。メニューが開いている間は `⌘,`(Command + カンマ)でも選べます。

- 設定ウィンドウのタイトルは「TatakiNote の設定」です。他のアプリのウィンドウより手前に開きます。
- TatakiNote を起動しただけでは開きません。「設定」を選んだときだけ開きます。
- すでに開いているときに「設定」を選んでも、ウィンドウは増えず、手前に出るだけです。
- メニューバーのアイコンを隠しているときの開き方は、[メニューバーのアイコンを隠す](#メニューバーのアイコンを隠す) を見てください。

## ウィンドウの見方

- 左のサイドバーに設定の種類が、上から「一般」「エディタ設定」「アプリ情報」の順に並びます。選ぶと、右にその種類の設定が出ます。開くたびに「一般」が選ばれた状態で始まります(「アプリ情報」などを出したまま閉じても、開き直すと「一般」です)。
- 右に、選んだ種類の設定が出ます。中身がウィンドウの高さより長いので、右側は縦にスクロールします。
- サイドバーは畳めません。
- サイドバーの下に「TatakiNote を終了」ボタンがあります。どの項目を選んでいても、右側をスクロールしていても、いつも押せます。押すと TatakiNote を終了します(パネルの下書きは消えます)。

## 一般の項目

「一般」には、上から次の項目が並びます。

| 項目 | 選択肢 | 既定値 | 詳しい説明 |
|---|---|---|---|
| 「パネルを開く・閉じる」 | ホットキーの記録ボックス | `⌥⇧Space`(Option + Shift + Space) | [ホットキーを変える](#ホットキーを変える) |
| 「確定キー」 | 記録ボックス(修飾キー付きの任意のキー) | 登録なし | [確定キーと確定送信キーを登録する](#確定キーと確定送信キーを登録する) |
| 「確定+送信キー」 | 記録ボックス(修飾キー付きの任意のキー) | `⌘↩`(Command + Return) | [確定キーと確定送信キーを登録する](#確定キーと確定送信キーを登録する) |
| 「パネルを出す位置」 | 「入力欄の近く」「挿入先のウィンドウがある画面」「マウスのある画面」「メインの画面」 | 「入力欄の近く」 | [パネルを出す位置を選ぶ](panel.md#パネルを出す位置を選ぶ) |
| 「自動表示」 | 「オフ」「全アプリ」「選んだアプリのみ」 | 「オフ」 | [自動表示を使う](auto-show.md#自動表示を使う) |
| 「対象のアプリ」 | アプリの一覧と「＋」「−」のボタン | 空 | [対象のアプリを選ぶ](auto-show.md#対象のアプリを選ぶ) |
| 「テーマ」 | 「システム」「ライト」「ダーク」 | 「システム」 | [テーマを選ぶ](#テーマを選ぶ) |
| 「起動」 | 「ログイン時に起動」のチェックボックス | オフ | [ログイン時に起動する](#ログイン時に起動する) |
| 「メニューバー」 | 「メニューバーのアイコンを隠す」のチェックボックス | オフ(アイコンを出す) | [メニューバーのアイコンを隠す](#メニューバーのアイコンを隠す) |

各項目の下には、次の説明文が出ています。

- 「パネルを開く・閉じる」: 「どのアプリを使っているときでも、このキーでパネルを開く・閉じるを切り替えます。」
- 「確定キー」: 「パネルでこのキーを押すと、書いた文章を元のアプリに挿入します(送信はしません)。修飾キー(⌘・⌥・⌃・⇧)と組み合わせたキーを登録できます。登録していない Enter は改行になります。初期設定では登録していません。登録していないときは、確定+送信キーでだけ挿入します。」
- 「確定+送信キー」: 「パネルでこのキーを押すと、書いた文章を挿入したあと、挿入先で Enter を送って送信します。初期設定は ⌘↩ です。送信は取り消せないので、送信せずに挿入したいときは確定キーを登録してください。」
- 「パネルを出す位置」: 「パネルを新しく開くときに出す位置です。「入力欄の近く」は、挿入先のアプリで選ばれている入力欄の近くに出します。入力欄の位置が分からないときは、挿入先のウィンドウがある画面の中央に出します。ほかの3つは、その画面の中央に出します(挿入先のウィンドウが分からないときは、マウスのある画面)。「メインの画面」は、システム設定の「ディスプレイ」でメインディスプレイにしている画面です。」
- 「自動表示」: 「入力欄を選んだだけでパネルを開きます。ホットキーは今までどおり使えます。」
- 「対象のアプリ」: 「「＋」で起動中のアプリから追加します。起動していないアプリは「その他…」から選べます。」
- 「テーマ」: 「「システム」は、Mac の外観モード(ライト・ダーク)に合わせます。メニューバーのメニューは、どれを選んでも Mac の外観モードのままです。」
- 「ログイン時に起動」: 「オンにすると、Mac にログインしたときに TatakiNote が起動します。システム設定の「ログイン項目」で外したときは、ここもオフになります。」
- 「メニューバーのアイコンを隠す」: 「隠している間は、TatakiNote をもう一度開く(Finder・Spotlight など)と、この設定画面が開きます。ホットキーと自動表示は今までどおり使えます。終了するときは、左下の「TatakiNote を終了」を押します。」

確定キーと確定+送信キーには、同じキーを登録できません(登録なしは両方にできます)。もう一方で使っているキーを登録しようとすると、受け付けられずに理由が表示されます([確定キーと確定送信キーを登録する](#確定キーと確定送信キーを登録する))。

## ホットキーを変える

1. 「パネルを開く・閉じる」の記録ボックスをクリックします。
2. 新しいキーの組み合わせを押します。
3. 以後、そのキーでパネルが開閉します。メニューの「パネルを開く」の右に出るキーの表示も、新しいキーに変わります。

- 設定ウィンドウを開いた直後は、記録ボックスは選ばれていません。開いた瞬間に記録が始まって、ホットキーが効かなくなるのを避けるためです。
- ホットキーの既定値は `⌥⇧Space` です。

## 確定キーと確定送信キーを登録する

「確定キー」「確定+送信キー」は、ホットキーと同じ記録ボックスで、修飾キー(⌘・⌥・⌃・⇧のいずれか)を含む好きなキーの組み合わせを登録します。

1. 「確定キー」または「確定+送信キー」の記録ボックスをクリックします。表示が「ショートカットを押す」に変わります。
2. 登録したいキーの組み合わせ(例 `⌘K`)を押します。
3. 受け付けられると、記録ボックスにそのキーの表記が出て記録が終わります。以後、パネルでそのキーを押すと確定(または確定+送信)します。

修飾キーを含まないキーや、ほかの用途で使っているキーは受け付けられません。押したキーが受け付けられなかったときは、記録ボックスの下に理由が表示され、記録は続きます(別のキーを押し直せます)。

| 押したキー | 受け付けない理由 |
|---|---|
| 修飾キーを含まないキー(文字キー、修飾キーなしの Return など) | 「⌘・⌥・⌃・⇧ のどれかと組み合わせたキーを押してください。」 |
| `esc`(修飾キー付きも含む) | 「esc はパネルを閉じるキーのため、修飾キーと組み合わせても登録できません。」 |
| 入力欄の[編集ショートカット](text-editing.md)のキー(`⌘A`・`⌘C`・`⌘D`・`⌘H`・`⌘L`・`⌘V`・`⌘X`・`⌘Z`・`⇧⌘Z`・`⌥↑`・`⌥↓`・`⇧⌥↑`・`⇧⌥↓`) | 「(そのキー) は入力欄の編集ショートカットで使っているため、登録できません。」 |
| 「パネルを開く・閉じる」のホットキーと同じキー | 「(そのキー) は「パネルを開く・閉じる」で使っているため、登録できません。」 |
| もう一方(確定キー / 確定+送信キー)で使っているキー | 「(そのキー) は「確定キー」(または「確定+送信キー」)で使っているため、登録できません。」 |

- 登録を消すには、記録ボックスの ×(登録があるときだけ出ます)を押すか、記録中に `Delete` / `Forward Delete` を押します。消すと「登録なし」になり、帯からその項目が消え、そのキーを押しても確定・確定+送信にはなりません。
- 登録せずに記録をやめる(登録は変わりません)には、記録中に修飾キーなしの `esc` を押すか、記録ボックスの外をクリックするか、設定ウィンドウがキーでなくなるようにします(閉じる・他のアプリに切り替えるなど)。
- 記録している間は、「パネルを開く・閉じる」のホットキーは効きません。記録が終わると元どおり効くようになります。
- 設定ウィンドウを開いた直後や `Tab` でフォーカスが来たときは記録が始まりません。記録ボックスをクリックしたときだけ始まります。

## テーマを選ぶ

「テーマ」で「システム」「ライト」「ダーク」から選びます。

- 選ぶと、開いたままの設定ウィンドウとアクセシビリティの許可の案内の外観が、すぐにそのテーマになります。
- 「システム」は、Mac の外観モード(ライト・ダーク)に合わせます。
- メニューバーのメニューは、どのテーマを選んでも Mac の外観モードのままです。

## ログイン時に起動する

「ログイン時に起動」をオンにすると、Mac にログインしたときに TatakiNote が自動で起動します。

- チェックの表示は、Mac に登録されている状態に合わせます。設定ウィンドウを開くたびと、システム設定から戻ってきたときに読み直すので、システム設定の「ログイン項目」で TatakiNote を外したときは、チェックもオフになります。
- Mac が許可を求めているときは、「システム設定の「ログイン項目」で TatakiNote を許可してください。許可するまで、ログイン時に起動しません。」と出ます。「システム設定を開く」ボタンで、システム設定を開けます。
- 登録できなかったときは、「ログイン項目に登録できませんでした。TatakiNote をアプリケーションフォルダから開いているか確かめて、もう一度オンにしてください。」と出て、チェックは付きません。
- 外せなかったときは、「ログイン項目から外せませんでした。システム設定の「ログイン項目」で TatakiNote を外してください。」と出ます。

## メニューバーのアイコンを隠す

「メニューバーのアイコンを隠す」をオンにすると、メニューバーの TatakiNote のアイコンが消えます。オフにすると戻ります。設定ウィンドウを開いたまま切り替えられます。

- アイコンを隠しても TatakiNote は終了しません。ホットキーと自動表示は、今までどおり使えます。起動し直しても、隠したままです。
- アイコンを隠している間はメニューが使えないので、TatakiNote をもう一度開く(Finder や Spotlight から開く)と、設定ウィンドウが開きます。アイコンを出しているときは、もう一度開いても何も開きません。
- 終了するときは、設定ウィンドウの「TatakiNote を終了」を押します。
- メニューバーの TatakiNote のアイコンを `⌘` を押しながらメニューバーの外へドラッグして外したときも、「メニューバーのアイコンを隠す」がオンになります。戻すときは、TatakiNote をもう一度開いて設定ウィンドウを出し、オフにします。
- アクセシビリティの許可が無いときは、アイコンを隠していても、起動時に許可の案内が開きます([アクセシビリティの許可](accessibility.md))。

## エディタ設定の項目

サイドバーの「エディタ設定」には、パネルの見た目と入力欄に関する項目が、上から次の順に並びます。

| 項目 | 選択肢 | 既定値 |
|---|---|---|
| 「フォント」 | 今のフォントの名前の表示と、「フォントパネルを開く」「システムフォントに戻す」の2つのボタン | 「システムフォント」 |
| 「文字サイズ」 | 10〜32 pt(1 pt ずつ) | 14 pt |
| 「透明度」 | 40〜100%(5% ずつ) | 100% |
| 「パネルの既定の大きさ」 | 幅と高さの数値(ステッパー付き)と、2つのボタン | 幅 520・高さ 340 |
| 「帯に出す項目」 | 「閉じる」「改行」「確定キー」「確定+送信キー」「文字数」「行数」のチェックボックス | すべてオン |
| 「ショートカットキー」 | 見るだけの一覧 | — |

各項目の下には、次の説明文が出ています。

- 「フォント」: 「パネルの入力欄の文字に使います。フォントパネルで選んだフォントと太さが、すぐに使われます。フォントパネルで変えた大きさは「文字サイズ」にも入ります。」
- 「文字サイズ」: 「10〜32 pt の間で選べます。」
- 「透明度」: 「パネル全体(背景と文字)の透け具合です。100% で透けません。40% より下にはできません。」
- 「パネルの既定の大きさ」: 「パネルを開いたときの大きさです(幅 320〜4000・高さ 160〜4000 pt)。変えると、次にパネルを開いたときから使います。」と、「パネルの端をドラッグして大きさを変えると、文章を挿入するまではその大きさで開きます(その間は、ここを変えてもパネルの大きさは変わりません)。「今のパネルの大きさを既定にする」は、ドラッグで大きさを変えた後に押せて、ドラッグで決めた大きさを既定にします(文章で伸びた高さは含みません)。」
- 「帯に出す項目」: 「パネルの下の帯に出す項目です。すべて外すと帯ごと消え、そのぶん入力欄が広がります。」
- 「ショートカットキー」: 「パネルの入力欄で使えるキーです(割り当ては変えられません)。改行・閉じる・確定のキーは、パネルの下の帯と「一般」で確かめられます。」

### フォントと文字サイズを変える

- 「フォント」の欄には、今使っているフォントの名前が出ます。何も選んでいないときは「システムフォント」です。
- 「フォントパネルを開く」を押すと、Mac 標準のフォントパネルが開きます。名前で探して、書体・太さ・サイズを選べます。日本語のフォントや等幅のフォントも選べます。
- フォントパネルで選ぶと、決定のボタンを押さなくても、フォントの名前の表示と、開いているパネルの入力欄の文字がすぐに変わります。太さも、選んだとおりに使われます。
- フォントパネルでサイズを変えると、「文字サイズ」にも同じ値が入ります。小数は四捨五入し、10 pt より小さい値は 10 pt、32 pt より大きい値は 32 pt になります。
- 「システムフォントに戻す」を押すと、フォントが「システムフォント」に戻ります。文字サイズは変わりません。すでにシステムフォントのときは押せません。
- フォントパネルを開いている間に、「文字サイズ」のステッパーや「システムフォントに戻す」で変えると、フォントパネルで選ばれている内容も同じになります。
- 設定ウィンドウを閉じると、開いているフォントパネルも閉じます。
- 選んだ書体が後から Mac から無くなったときは、同じフォントの標準の太さで表示します。そのフォントごと無いときは、システムフォントで表示し、名前の表示も「システムフォント」になります。
- 文字サイズは、「文字サイズ」の右のステッパーで 1 pt ずつ変えます。今の値が「14 pt」のように左に出ます。
- フォントと文字サイズは、パネルの入力欄の文字に効きます。

### 透明度を変える

- 「透明度」のスライダーで、パネル全体(背景と文字)の透け具合を変えます。右に「85%」のように今の値が出ます。100% では透けません。
- 40% より下にはできません。

### パネルの既定の大きさを変える

「パネルの既定の大きさ」は、パネルを閉じた状態から開いたときの大きさです。

- 「幅」「高さ」の欄に数値を打つか、右のステッパー(10 ずつ)で変えます。範囲は幅 320〜4000・高さ 160〜4000 です。範囲の外の数値を打つと、いちばん近い端の値になります。数字でない文字を打って確定したときは、前の値に戻ります。
- 「今のパネルの大きさを既定にする」は、パネルの端をドラッグして好みの大きさにした後に押せます。ドラッグで決めた大きさが、幅と高さの欄に入ります。パネルを開いただけのとき、起動した直後、文章を挿入した後は、押せません。設定ウィンドウを開いたままでも、ドラッグすると押せるようになります。
- 「初期値に戻す」は、幅 520・高さ 340 に戻します。
- ドラッグで変えた大きさが保たれている間は、ここを変えても、挿入するまではドラッグした大きさで開きます([パネルの大きさ](panel.md#パネルの大きさ))。
- 変えた大きさは、次にパネルを閉じた状態から開くときと、文章を挿入した後に次に開くときから使います。

### 帯に出す項目を選ぶ

- 「帯に出す項目」のチェックボックスで、パネルの下の帯に出す項目を選びます(帯の見方は [パネルの下の帯](panel.md#パネルの下の帯))。
- 「確定キー」「確定+送信キー」は、「一般」でそのキーを登録していないと、チェックが付いていても帯に出ません。そのあいだは、項目の下に「キーを登録していないあいだは帯に出ません」と出ます。
- すべて外すと、帯と区切り線ごと消えて、そのぶん入力欄が広がります。

### ショートカットキーの一覧

「ショートカットキー」には、パネルの入力欄で使えるキーが一覧で出ます。見るだけで、ここからキーは変えられません。

| キー | 操作 |
|---|---|
| `⌥↑` / `⌥↓` | 行を上 / 下の行と入れ替える |
| `⇧⌥↑` / `⇧⌥↓` | 行を下に複製する |
| `⌘C` | 選択なしで行ごとコピー |
| `⌘X` | 選択なしで行ごと切り取り |
| `⌘V` | 行ごとコピー・切り取りした行を上に貼り付け |
| `⌘L` | 行を選択(続けて押すと下へ広げる) |
| `⌘D` | カーソルのある単語を選択 |

それぞれの動きは [入力欄の編集ショートカット](text-editing.md) を見てください。

## アプリ情報の項目

サイドバーの「アプリ情報」には、次の3つが出ます。

- 「バージョン」: 「1.2 (34)」のように、バージョン番号とかっこ付きのビルド番号が出ます。説明文は「かっこの中はビルド番号です。」です。読めない側は「不明」と出ます。
- 「権限」: アクセシビリティの許可の状態です。許可があれば「アクセシビリティの許可があります。」と出ます。許可が無いときは、許可が無いことと許可の手順、「システム設定を開く」ボタンが出ます。
- 「チュートリアル」: 「チュートリアルを開く」ボタンで、練習用の入力欄で使い方をたどるウィンドウを開きます。説明文は「練習用の入力欄で、パネルを開いて書いて挿入するまでをたどります。」です([チュートリアル](tutorial.md))。

- 表示している間に許可を変えると、設定ウィンドウを開き直さなくても、数秒のうちに表示が変わります。
- 許可の手順と、許可が無いときに使えなくなる機能は [アクセシビリティの許可](accessibility.md) を見てください。

## 設定の保存

- どの項目も、変えた瞬間に保存されます。保存ボタンはありません。ただし「ログイン時に起動」は、Mac に登録される設定なので、保存ではなく Mac 側の状態がそのまま表示されます。
- TatakiNote を起動し直さなくても、次の操作から効きます。起動し直しても、変えた値は残ります。
- 確定キーと確定+送信キーは、パネルが開いていても、次のキー入力から効きます。
- 「パネルを出す位置」は、次にパネルを閉じた状態から開くときから効きます。
- 「パネルの既定の大きさ」は、次にパネルを閉じた状態から開くときから効きます。
- 「自動表示」と「対象のアプリ」は、次にアプリが前面になったところから効きます([設定を変えたとき](auto-show.md#設定を変えたとき))。
- 保存した値が読めないとき(新しいバージョンの TatakiNote で保存した値を古いバージョンで読んだときなど)は、その項目は既定値になります。
