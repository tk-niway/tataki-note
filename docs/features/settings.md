# 設定ウィンドウ

設定ウィンドウでは、パネルの動きや見た目を変えられます。項目は「一般」「ホットキーとキー操作」「パネル」「情報」の4つに分かれています。
「一般」ではテーマ・アニメーション・ログイン時に起動・メニューバーと Dock のアイコンの表示・⌘Q での終了前の確認・履歴の削除、「ホットキーとキー操作」ではパネルを開くホットキー・自動表示・確定のキー、「パネル」ではパネルを出す位置と、パネルの文字・透明度・既定の大きさ・帯の項目・挿入先の枠線を変えられます。「情報」では、バージョンとアクセシビリティの許可の状態を確かめ、チュートリアルを開けます。
変えた値はその場で保存され、TatakiNote を起動し直さなくても次の操作から効きます。

## 設定ウィンドウを開く

1. メニューバーの TatakiNote のアイコンをクリックします。
2. 「設定」を選びます。メニューが開いている間は `⌘,`(Command + カンマ)でも選べます。

- 設定ウィンドウのタイトルは「TatakiNote の設定」です。他のアプリのウィンドウより手前に開きます。
- パネルを開いているときは、`⌘,`(Command + カンマ)か、サイドバーの左下にある歯車と「設定」のボタンでも開けます。パネルは開いたままです。パネルが開いたまま設定ウィンドウを閉じると、キー入力はパネルに戻ります。サイドバーの開き方は [サイドバーで探して呼び出す](drafts-and-history.md#サイドバーで探して呼び出す) を見てください。
- TatakiNote を起動しただけでは開きません。「設定」を選んだときか、パネルで `⌘,` か「設定」のボタンを押したときだけ開きます。
- すでに開いているときに「設定」を選んでも、ウィンドウは増えず、手前に出るだけです。
- メニューバーのアイコンを表示していないときの開き方は、[メニューバーのアイコン](#メニューバーのアイコン) を見てください。

## 新しい書きかけのモードを選ぶ

「ホットキーとキー操作」の「挿入と送信」にある「モード」で、新しい書きかけを「インサート」と「ノート」のどちらで始めるかを選びます。初期値は「インサート」です。選んだ値はその場で保存され、起動し直しても残ります。

- 新しい書きかけは、TatakiNote を起動したとき・`⌘N` や新規作成のアイコンで新しい書きかけにしたとき・文章を挿入できたあとに始まります。そのときに、ここで選んだモードになります。
- 下書きや履歴を開いたとき、パネルを閉じて開き直したとき、挿入できずに文章がパネルに戻ったときは、モードは変わりません。
- ここで選んだ値を変えても、いま書いている書きかけのモードは変わりません。いまの書きかけは、パネルで `⌘E` を押して切り替えます。

モードごとの動きは [書きかけのモード](panel.md#書きかけのモード) を見てください。

確定+挿入キーと確定+送信キーが両方とも登録なしのまま TatakiNote を起動すると、初期値の `⇧⌘↩` と `⌘↩` が登録されます(ホットキーと同じキーは登録されません)。

## ウィンドウの見方

- 左のサイドバーに、設定の種類が、上から「一般」「ホットキーとキー操作」「パネル」「情報」の順に並びます。選ぶと、右にその種類の設定が出ます。開くたびに「一般」が選ばれた状態で始まります(「ホットキーとキー操作」などを出したまま閉じても、開き直すと「一般」です)。
- 右の上に選んだ種類の名前が見出しで出て、その下に設定が出ます。設定は「外観」「履歴」のように、見出しの付いたまとまりに分かれ、各項目は角丸のカードの中に並びます。中身がウィンドウの高さより長いときは、見出しの下が縦にスクロールします。
- オンとオフを切り替える項目は、スイッチで切り替えます。
- サイドバーは畳めません。
- サイドバーの下に「TatakiNote を終了」ボタンがあります。どの項目を選んでいても、右側をスクロールしていても、いつも押せます。押すと TatakiNote を終了します(パネルに書きかけがあれば、履歴に残ります)。

- 「メニューバーにアイコンを表示」: 「オフの間は、パネルの「設定」のボタンか ⌘, でこの画面を開きます。終了は左下の「TatakiNote を終了」から。」

自動表示の設定は、「ホットキーとキー操作」にあります([自動で開く](#自動で開く))。

### テーマを選ぶ

「テーマ」で「システム」「ライト」「ダーク」から選びます。

- 選ぶと、開いたままの設定ウィンドウとアクセシビリティの許可の案内の外観が、すぐにそのテーマになります。
- 「システム」は、Mac の外観モード(ライト・ダーク)に合わせます。
- メニューバーのメニューは、どのテーマを選んでも Mac の外観モードのままです。

### アニメーションを切り替える

「アニメーション」で「システム」「オン」「オフ」から選びます。初期値は「オン」です。パネル・サイドバー・設定ウィンドウ・チュートリアルなど、TatakiNote の動きすべてに効きます。

- 「オン」: すべての動きを使います。Mac の「視差効果を減らす」がオンでも動きます。
- 「オフ」: 動きを使いません。
- 「システム」: Mac の「視差効果を減らす」がオンのときは「オフ」と同じ、オフのときは「オン」と同じになります。
- 変えると、次の動きから効きます。動いている途中の動きは、そのまま最後まで動きます。
- オフにすると、パネルとサイドバーは動きなしですぐに開閉し、`⌘H` は標準の動きのとおりすぐに TatakiNote を隠します([開閉の動き](panel.md#開閉の動き))。
- 動きが知らせを兼ねている所は、動き以外で知らせます。保存では、文章の写しは飛ばず、「下書きに保存しました」だけが出ます(上書き保存でも出ます)。保存した下書きの行は、薄れずに少しの間だけ色が付きます。空のまま確定や `⌘S` をしたときは、パネルは揺れず、警告音が鳴ります。「挿入先なし」は、揺れずにオレンジ色に光ります。
- 「アニメーション」にかかわらず、サイドバーの一覧の行が滑り込む動きと、設定ウィンドウで項目を切り替えるときの動きはありません。
### ログイン時に起動する

「ログイン時に起動」をオンにすると、Mac にログインしたときに TatakiNote が自動で起動します。

- スイッチの表示は、Mac に登録されている状態に合わせます。設定ウィンドウを開くたびと、システム設定から戻ってきたときに読み直すので、システム設定の「ログイン項目」で TatakiNote を外したときは、スイッチもオフになります。
- Mac が許可を求めているときは、「システム設定の「ログイン項目」で TatakiNote を許可してください。許可するまで、ログイン時に起動しません。」と出ます。「システム設定を開く」ボタンで、システム設定を開けます。
- 登録できなかったときは、「ログイン項目に登録できませんでした。TatakiNote をアプリケーションフォルダから開いているか確かめて、もう一度オンにしてください。」と出て、スイッチはオンになりません。
- 外せなかったときは、「ログイン項目から外せませんでした。システム設定の「ログイン項目」で TatakiNote を外してください。」と出ます。

### メニューバーのアイコン

「メニューバーにアイコンを表示」をオフにすると、メニューバーの TatakiNote のアイコンが消えます。オンにすると戻ります。初期値はオンです。設定ウィンドウを開いたまま切り替えられます。

- アイコンを表示しなくても TatakiNote は終了しません。ホットキーと自動表示は、今までどおり使えます。起動し直しても、表示しないままです。
- アイコンを表示していない間はメニューが使えないので、設定ウィンドウは、パネルの `⌘,` かサイドバーの「設定」のボタンで開きます。TatakiNote をもう一度開く(Finder や Spotlight から開く)と、パネルが開きます([パネルを開く](panel.md#パネルを開く))。
- 終了するときは、設定ウィンドウの「TatakiNote を終了」を押します。
- メニューバーの TatakiNote のアイコンを `⌘` を押しながらメニューバーの外へドラッグして外したときも、「メニューバーにアイコンを表示」がオフになります。戻すときは、パネルから設定ウィンドウを開き、オンにします。

### Dock のアイコン

「Dock にアイコンを表示」をオンにすると、TatakiNote のアイコンが Dock に出ます。オフにすると消えます。初期値はオンです。設定ウィンドウを開いたまま切り替えられ、起動し直さなくても変わります。

- オフにしても、メニューバーのアイコンとホットキーは今までどおり使えます。
- Dock のアイコンを表示していないときも、Finder や Spotlight から TatakiNote を開くと、パネルが開きます。
- 「メニューバーにアイコンを表示」とは別の設定です。両方をオフにすると、Dock にもメニューバーにもアイコンが出ません。

### 終了前の確認

「⌘Q で終了前に確認」をオンにすると、`⌘Q`(Command + Q)を押したときに、すぐ終了せず「TatakiNote を終了しますか?」の窓が出ます。初期値はオンです。

- 窓には「終了すると、ホットキーでパネルを開けなくなります。書きかけは履歴に残ります。」と出ます。「終了」(`↩`)で終了し、「キャンセル」(`esc`)で閉じて元の画面に戻ります。
- 「今後は確かめない」(`⌘D` でも切り替えられます)にチェックして「終了」を選ぶと、この設定がオフになり、以後は `⌘Q` ですぐ終了します。「キャンセル」を選んだときは、設定は変わりません。
- 日本語入力(ローマ字入力・かな入力)がオンのときも、英字のときも、パネルに入力しているときも、設定ウィンドウが前面のときも、Dock のアイコンを表示していてもいなくても、同じように窓が出ます。
- 窓が出ている間は、`⌘Q` を押しても何も起きず、ホットキーでもパネルは開閉しません。
- メニューバーのメニューの「終了」のクリックと、設定ウィンドウの「TatakiNote を終了」、Dock のアイコンのメニューの「終了」、ログアウトや再起動は、この設定に関係なく、確認せずに終了します。窓が出ている間もログアウトできます。
- ホットキーなどの記録ボックスで記録している間と、`⌘Q` を確定のキーに登録していてパネルでそれを押したときは、確認の窓は出ません。
- アクセシビリティの許可が無いときは、アイコンを表示していなくても、起動時に許可の案内が開きます([アクセシビリティの許可](accessibility.md))。

### 履歴をすべて削除する

「履歴」の行には、挿入した文章の件数が「挿入した文章 12 件」のように出ます。「履歴をすべて削除」を押すと、同じ行の中で、説明が「挿入の履歴をすべて削除しますか? この操作は元に戻せません。」に変わり、ボタンが「キャンセル」と「削除する」に変わります。「削除する」で、サイドバーの「履歴」が空になります。「キャンセル」(または `esc`)では何も消えません。

- 削除すると、件数が 0 まで数え下がり、「✓ 削除しました」と出ます。
- 確認の途中で別の項目に切り替えたり、設定ウィンドウを閉じたりすると、確認は消えて、何も消えないまま元の行に戻ります。
- 消えるのは履歴だけです。保存した下書きは残ります。
- 履歴が空のときは、ボタンは押せません。
- 履歴の1件だけを消すときは、サイドバーで行を消します([削除する](drafts-and-history.md#削除する))。

### 履歴に残す件数を変える

「履歴」の「残す件数」で、履歴に残す件数の上限を決めます。「挿入した文章」の件数には、挿入していない書きかけ([書きかけは履歴に残る](drafts-and-history.md#書きかけは履歴に残る))も含まれます。

- 数値を打つか、右のステッパー(10 ずつ)で変えます。範囲は 10〜1000 件で、初期値は 200 件です。範囲の外の数値を打つと、いちばん近い端の値になります。
- 上限を超えた分は、古いものから消えます。書きかけが別の文章を開くたびに履歴へ移るので、件数を少なくしすぎると、行を何度か行き来しただけで古い履歴が押し出されます。
- 今ある件数より小さくすると、説明が「(件数) 件にすると、古い履歴が (消える件数) 件消えます。この操作は元に戻せません。」に変わり、ボタンが「キャンセル」と「変更する」に変わります。「変更する」で古い履歴が消えます。「キャンセル」(または `esc`)では何も変わらず、数値も元に戻ります。
- 消えない範囲の変更(件数を増やす、今の件数以上にする)は、確認なしですぐ変わります。

| 「自動で開く」 | 「対象のアプリ」 | アプリのチップの並びと「＋ 追加」 | 空 | [対象のアプリを選ぶ](auto-show.md#対象のアプリを選ぶ) |
| 「挿入と送信」 | 「モード」 | 「インサート」「ノート」 | 「インサート」 | [新しい書きかけのモードを選ぶ](#新しい書きかけのモードを選ぶ) |
| 「挿入と送信」 | 「確定+挿入キー」 | 記録ボックス(修飾キー付きの任意のキー) | `⇧⌘↩`(Shift + Command + Return) | [確定+挿入キーと確定+送信キーを登録する](#確定挿入キーと確定送信キーを登録する) |
| 「挿入と送信」 | 「確定+送信キー」 | 記録ボックス(修飾キー付きの任意のキー) | `⌘↩`(Command + Return) | [確定+挿入キーと確定+送信キーを登録する](#確定挿入キーと確定送信キーを登録する) |
| 「パネルの中で使えるキー」 | ショートカットキー | 見るだけの一覧(「変更できません」) | — | [ショートカットキーの一覧](#ショートカットキーの一覧) |

各項目の下には、次の説明文が出ています。

- 「パネルを開く・閉じる」: 「どのアプリからでも、このキーでパネルを開く・閉じるを切り替えます。」
- 「確定+挿入キー」: 「書いた文章を元のアプリに挿入します(送信はしません)。初期値は ⇧⌘↩ です。」
- 「確定+送信キー」: 「挿入したあと Enter を送って送信します。送信は取り消せません。初期値は ⌘↩ です。」
- 「モード」: 「新しい書きかけ(起動したとき・⌘N で新しくしたとき・挿入したあと)を、このモードで始めます。ノートでは挿入・送信せず、確定のキーは改行になります。今の書きかけのモードは、パネルで ⌘E を押して切り替えられます。」
- 「自動表示」: 「入力欄を選ぶだけでパネルを開きます。」
- 「対象のアプリ」: 「「＋ 追加」で起動中のアプリを、「その他…」でそれ以外を選べます。」
- 「挿入と送信」の下: 「記録ボックスをクリックしてキーを押します。esc で取り消します。」
- 「パネルの中で使えるキー」の下: 「割り当ては変えられません。確定のキーは上の「確定+挿入キー」「確定+送信キー」で確かめられます。」

### 自動で開く

「自動表示」を、横に並んだ「オフ」「全アプリ」「選んだアプリのみ」から選びます。「選んだアプリのみ」にすると、「対象のアプリ」に選んだアプリが並びます。アプリごとの小さなチップの「×」で外し、「＋ 追加」で足します。「オフ」「全アプリ」のときは、チップの並びと「＋ 追加」は薄くなって押せません。使い方は [入力欄を選んだらパネルを自動で出す](auto-show.md) を見てください。

確定+挿入キーと確定+送信キーには、同じキーを登録できません。もう一方で使っているキーを登録しようとすると、受け付けられずに理由が表示されます([確定+挿入キーと確定+送信キーを登録する](#確定挿入キーと確定送信キーを登録する))。両方を登録なしにすることはできません(最後の1つは消せません)。

### ホットキーを変える

1. 「ホットキーとキー操作」を開き、「パネルを開く・閉じる」の記録ボックスをクリックします。
2. 新しいキーの組み合わせを押します。
3. 以後、そのキーでパネルが開閉します。メニューの「パネルを開く」の右に出るキーの表示も、新しいキーに変わります。

- 「ホットキーとキー操作」を出した直後は、記録ボックスは選ばれていません。出した瞬間に記録が始まって、ホットキーが効かなくなるのを避けるためです。
- ホットキーの初期値は `⌥⇧Space` です。
- `⌘K`・`⌘S`・`⌘N`・`⌘E`・`⌘B`・`⌘,`・`⇧⌘S` は登録できません。押すと、直前のキーに戻り、記録ボックスの下に「(そのキー) はパネルの検索・下書きの保存・新しい書きかけ・モードの切り替え・サイドバーの開閉・設定を開く・ファイルへの書き出しの操作(⌘K・⌘S・⌘N・⌘E・⌘B・⌘,・⇧⌘S)で使っているため、登録できません。」と出ます。

### 確定+挿入キーと確定+送信キーを登録する

「確定+挿入キー」「確定+送信キー」は、ホットキーと同じ記録ボックスで、修飾キー(⌘・⌥・⌃・⇧のいずれか)を含む好きなキーの組み合わせを登録します。

1. 「ホットキーとキー操作」の「挿入と送信」で、「確定+挿入キー」または「確定+送信キー」の記録ボックスをクリックします。表示が「ショートカットを押す」に変わります。
2. 登録したいキーの組み合わせ(例 `⌘J`)を押します。
3. 受け付けられると、記録ボックスにそのキーが1つずつのキーの絵で出て、少し弾んで記録が終わります。以後、パネルでそのキーを押すと確定+挿入(または確定+送信)します。

修飾キーを含まないキーや、ほかの用途で使っているキーは受け付けられません。押したキーが受け付けられなかったときは、記録ボックスが横に揺れ、下に理由が表示され、記録は続きます(別のキーを押し直せます)。

| 押したキー | 受け付けない理由 |
|---|---|
| 修飾キーを含まないキー(文字キー、修飾キーなしの Return など) | 「⌘・⌥・⌃・⇧ のどれかと組み合わせたキーを押してください。」 |
| `esc`(修飾キー付きも含む) | 「esc はパネルを閉じるキーのため、修飾キーと組み合わせても登録できません。」 |
| `⌘H`(パネルを閉じるキー) | 「⌘H はパネルを閉じるキーのため、登録できません。」 |
| 入力欄の[編集ショートカット](text-editing.md)のキー(`⌘A`・`⌘C`・`⌘D`・`⌘L`・`⌘V`・`⌘X`・`⌘Z`・`⇧⌘Z`・`⌥↑`・`⌥↓`・`⇧⌥↑`・`⇧⌥↓`) | 「(そのキー) は入力欄の編集ショートカットで使っているため、登録できません。」 |
| `⌘K`・`⌘S`・`⌘N`・`⌘E`・`⌘B`・`⌘,`・`⇧⌘S`(パネルの検索・保存・新規・モードの切り替え・サイドバーの開閉・設定・ファイルへの書き出しのキー) | 「(そのキー) はパネルの検索・下書きの保存・新しい書きかけ・モードの切り替え・サイドバーの開閉・設定を開く・ファイルへの書き出しの操作(⌘K・⌘S・⌘N・⌘E・⌘B・⌘,・⇧⌘S)で使っているため、登録できません。」 |
| 「パネルを開く・閉じる」のホットキーと同じキー | 「(そのキー) は「パネルを開く・閉じる」で使っているため、登録できません。」 |
| もう一方(確定+挿入キー / 確定+送信キー)で使っているキー | 「(そのキー) は「確定+挿入キー」(または「確定+送信キー」)で使っているため、登録できません。」 |

- 登録を消すには、記録ボックスの ×(登録があるときだけ出ます)を押すか、記録中に `Delete` / `Forward Delete` を押します。消すと「登録なし」になり、帯からその項目が消え、そのキーを押しても確定+挿入・確定+送信にはなりません。
- もう一方が登録なしのときは、消せません。「確定+挿入キーと確定+送信キーの両方を未登録にはできません。挿入せずに書くときは、パネルで ⌘E を押してノートにしてください。」と出ます。
- 登録せずに記録をやめる(登録は変わりません)には、記録中に修飾キーなしの `esc` を押すか、記録ボックスの外をクリックするか、設定ウィンドウがキーでなくなるようにします(閉じる・他のアプリに切り替えるなど)。記録中にサイドバーで別の種類を選んでも、記録は終わります。
- 記録している間は、「パネルを開く・閉じる」のホットキーは効きません。記録が終わると元どおり効くようになります。
- 設定ウィンドウを開いた直後や、「ホットキーとキー操作」に切り替えた直後、`Tab` でフォーカスが来たときは記録が始まりません。記録ボックスをクリックしたときだけ始まります。

### ショートカットキーの一覧

「パネルの中で使えるキー」には、パネルの入力欄で使えるキーが、「行の操作」「コピーと貼り付け」「下書き」「表示」の4つのカードに分かれて出ます。キーは1つずつのキーの絵で出ます。見るだけで、ここからキーは変えられません(見出しの横に「変更できません」と出ます)。

| 分類 | キー | 操作 |
|---|---|---|
| 行の操作 | `⌥↑` / `⌥↓` | 行を上 / 下の行と入れ替える |
| 行の操作 | `⇧⌥↑` / `⇧⌥↓` | 行を下に複製する |
| 行の操作 | `⌘L` | 行を選択(続けて押すと下へ広げる) |
| 行の操作 | `⌘D` | カーソルのある単語を選択 |
| コピーと貼り付け | `⌘C` | 選択なしで行ごとコピー |
| コピーと貼り付け | `⌘X` | 選択なしで行ごと切り取り |
| コピーと貼り付け | `⌘V` | 行ごとコピー・切り取りした行を上に貼り付け |
| 下書き | `⌘S` | 下書きに保存する |
| 下書き | `⇧⌘S` | ファイルに書き出す |
| 下書き | `⌘N` | 新しい書きかけにする |
| 下書き | `⌘E` | インサートとノートを切り替える |
| 下書き | `⌘K` | 下書きと履歴を検索する(サイドバーを開く) |
| 表示 | `⌘B` | サイドバーを開く・閉じる |
| 表示 | `⌘,` | 設定を開く |

編集のキーの動きは [入力欄の編集ショートカット](text-editing.md)、`⌘K`・`⌘S`・`⇧⌘S`・`⌘N`・`⌘B` の動きは [下書きと履歴](drafts-and-history.md)、`⌘E` の動きは [書きかけのモード](panel.md#書きかけのモード) を見てください。

## パネルの項目

「パネル」には、パネルを出す位置と、パネルの見た目に関する項目が、上から次の順に並びます。

| まとまり | 項目 | 選択肢 | 初期値 |
|---|---|---|---|
| 「パネルを出す位置」 | 4つのタイル | 「入力欄の近く」「挿入先のウィンドウがある画面」「マウスの近く」「メインの画面」 | 「入力欄の近く」 |
| 「フォントと透明度」 | 「フォント」 | 今のフォントの名前の表示と、「システムフォントに戻す」「変更…」の2つのボタン | 「システムフォント」 |
| 「フォントと透明度」 | 「文字サイズ」 | 10〜32 pt(1 pt ずつ) | 14 pt |
| 「フォントと透明度」 | 「透明度」 | 40〜100%(5% ずつ) | 100% |
| 「パネルのサイズ」 | 「幅 × 高さ」 | 幅と高さの数値(ステッパー付き)と、2つのボタン | 幅 520・高さ 340 |
| 「帯に出す項目」 | 「閉じる」「改行」「確定+挿入キー」「確定+送信キー」「文字数」「行数」 | スイッチ | すべてオン |
| 「挿入先の枠線」 | 「挿入先の入力欄を枠線で囲む」 | スイッチ | オン |

「パネルを出す位置」の4つのタイルには、それぞれ画面の小さな図が付いています。選んでいるタイルは枠が色付きになり、図の中のパネルが弾みます。

「挿入先の枠線」のスイッチは、書きかけがノートのときでも押せます。ノートの書きかけでは枠線は出ず、インサートに戻すとその場で出ます([書きかけのモード](panel.md#書きかけのモード))。

次の項目の下には、説明文が出ています。「パネルを出す位置」「フォント」「文字サイズ」「パネルのサイズ」には説明文はありません。位置の選び方は [パネルを出す位置を選ぶ](panel.md#パネルを出す位置を選ぶ) を見てください。

- 「透明度」: 「パネル背景の透明度」
- 「帯に出す項目」: 「すべて外すと帯ごと消えます。」
- 「挿入先の枠線」: 「パネルを開いている間、挿入先の入力欄を枠線で囲みます。」詳しくは [挿入先を見分ける](insert-and-send.md#挿入先を見分ける) を見てください。

### フォントと文字サイズを変える

- 「フォント」の欄には、今使っているフォントの名前が、そのフォントの書体で出ます。何も選んでいないときは「システムフォント」です。
- 「変更…」を押すと、Mac 標準のフォントパネルが開きます。名前で探して、書体・太さ・サイズを選べます。日本語のフォントや等幅のフォントも選べます。
- フォントパネルで選ぶと、決定のボタンを押さなくても、フォントの名前の表示と、開いているパネルの入力欄の文字がすぐに変わります。太さも、選んだとおりに使われます。
- フォントパネルでサイズを変えると、「文字サイズ」にも同じ値が入ります。小数は四捨五入し、10 pt より小さい値は 10 pt、32 pt より大きい値は 32 pt になります。
- 「システムフォントに戻す」を押すと、フォントが「システムフォント」に戻ります。文字サイズは変わりません。すでにシステムフォントのときは押せません。
- フォントパネルを開いている間に、「文字サイズ」のステッパーや「システムフォントに戻す」で変えると、フォントパネルで選ばれている内容も同じになります。
- 設定ウィンドウを閉じると、開いているフォントパネルも閉じます。
- 選んだ書体が後から Mac から無くなったときは、同じフォントの標準の太さで表示します。そのフォントごと無いときは、システムフォントで表示し、名前の表示も「システムフォント」になります。
- 文字サイズは、「文字サイズ」の右のステッパーで 1 pt ずつ変えます。今の値が「14 pt」のように左に出ます。
- フォントと文字サイズは、パネルの入力欄の文字に効きます。

### 透明度を変える

- 「透明度」のスライダーで、パネル全体(背景と文字)の透け具合を変えます。右に「85%」のように今の値が出ます。100% では透けません。
- 40% より下にはできません。

### パネルの既定の大きさを変える

「パネルのサイズ」は、パネルを閉じた状態から開いたときの大きさ(既定の大きさ)です。

- 「幅」「高さ」の欄に数値を打つか、右のステッパー(10 ずつ)で変えます。範囲は幅 320〜4000・高さ 160〜4000 です。範囲の外の数値を打つと、いちばん近い端の値になります。数字でない文字を打って確定したときは、前の値に戻ります。
- 「今のパネルサイズを既定にする」は、パネルの端をドラッグして好みの大きさにした後に押せます。ドラッグで決めた大きさが、幅と高さの欄に入ります。パネルを開いただけのとき、起動した直後、文章を挿入した後、空のパネルを閉じて開き直した後は、押せません。設定ウィンドウを開いたままでも、ドラッグすると押せるようになります。
- 既定にする大きさは、サイドバーの幅を含まない、文章の部分の大きさです。サイドバーを開いたままドラッグした大きさも、同じです。
- 「初期値に戻す」は、幅 520・高さ 340 に戻します。
- 文章が入ったまま閉じたパネルは、ここを変えても、挿入するまではドラッグした大きさで開きます。空のパネルは、いつも既定の大きさで開きます([パネルの大きさ](panel.md#パネルの大きさ))。
- 変えた大きさは、次にパネルを閉じた状態から開くときと、文章を挿入した後に次に開くときから使います。

### 帯に出す項目を選ぶ

- 「帯に出す項目」のスイッチで、パネルの下の帯に出す項目を選びます(帯の見方は [パネルの下の帯](panel.md#パネルの下の帯))。
- 「確定+挿入キー」「確定+送信キー」は、設定の「ホットキーとキー操作」でそのキーを登録していないと、スイッチがオンでも帯に出ません。そのあいだは、項目の下に「キーを登録していないあいだは帯に出ません」と出ます。書きかけがノートのあいだは、スイッチがオンでも、確定のキーのヒントは帯に出ません。
- すべて外すと、帯と区切り線ごと消えて、そのぶん入力欄が広がります。

## 情報の項目

サイドバーの「情報」には、上にアプリのアイコンと「TatakiNote」の名前、「バージョン 1.2 (34)」のようなバージョンが出て、その下に次の2つが出ます。

- アイコンとバージョン: バージョン番号とかっこ付きのビルド番号が出ます。説明文は「かっこの中はビルド番号です。」です。読めない側は「不明」と出ます。アイコンを叩く(クリックする)と、アイコンが弾み、「トン」「タン」「カタッ」「ターン!」の順に言葉が飛びます(画面の下に「アイコンを叩いてみてください」と出ています)。この動きは、「アニメーション」の設定にかかわらず、いつも動きます。
- 「アクセシビリティの許可」: 説明文は「文章を入力欄に挿入するのに必要です。」です。右のバッジに今の状態が出ます。許可があれば「許可されています」(緑)、無ければ「許可されていません」(オレンジ)です。許可が無いときは、バッジの下に許可の手順と「システム設定を開く」ボタンが出ます。
- 「チュートリアル」: 「チュートリアルを開く」ボタンで、練習用のチャットで使い方をたどるウィンドウを開きます。説明文は「練習用のチャットで、書いて送るまでを試します。」です([チュートリアル](tutorial.md))。

- 表示している間に許可を変えると、設定ウィンドウを開き直さなくても、数秒のうちに表示が変わります。
- 許可の手順と、許可が無いときに使えなくなる機能は [アクセシビリティの許可](accessibility.md) を見てください。

## 設定の保存

- どの項目も、変えた瞬間に保存されます。保存ボタンはありません。ただし「ログイン時に起動」は、Mac に登録される設定なので、保存ではなく Mac 側の状態がそのまま表示されます。
- TatakiNote を起動し直さなくても、次の操作から効きます。起動し直しても、変えた値は残ります。
- 確定+挿入キーと確定+送信キーは、パネルが開いていても、次のキー入力から効きます。
- 「モード」は、次に新しい書きかけを始めるときから効きます。いまの書きかけのモードは変わりません。
- 「パネルを出す位置」は、次にパネルを閉じた状態から開くときから効きます。
- 「パネルのサイズ」は、次にパネルを閉じた状態から開くときから効きます。
- 「自動表示」と「対象のアプリ」は、次にアプリが前面になったところから効きます([設定を変えたとき](auto-show.md#設定を変えたとき))。
- 保存した値が読めないとき(新しいバージョンの TatakiNote で保存した値を古いバージョンで読んだときなど)は、その項目は初期値になります。
