# アクセシビリティの許可

TatakiNote が書いた文章を他のアプリに入れるには、macOS の「アクセシビリティ」の許可が要ります。
許可が無いときは、TatakiNote が案内のウィンドウを開いて、許可の手順を示します。

## なぜ許可が要るか

次の機能に、アクセシビリティの許可が要ります。

| 機能 | 許可が無いとき |
|---|---|
| 挿入(確定+挿入・確定+送信。[書いた文章を挿入する・送信する](insert-and-send.md)) | 確定しても挿入されず、パネルが閉じて案内が開きます。書いた文章はパネルの下書きに残ります |
| 自動表示([入力欄を選んだらパネルを自動で出す](auto-show.md)) | 入力欄を選んでも、パネルは自動では開きません |
| 「パネルを出す位置」の「入力欄の近く」([入力欄の近くに出るとき](panel.md#入力欄の近くに出るとき)) | 入力欄の位置が分からないので、入力欄の近くには出ず、「挿入先のウィンドウがある画面」と同じ画面の中央に出ます |

パネルを開いて書くことは、許可が無くてもできます。

## 案内が開く場面

案内のウィンドウのタイトルは「アクセシビリティの許可」です。次の場面で開きます。

| 場面 | 開く条件 | 案内の内容 |
|---|---|---|
| 起動したとき | 許可が無いとき(許可があれば開きません。ただし初めて起動したときに許可があれば、案内ではなく[チュートリアル](tutorial.md)が開きます) | 許可が無いことと、許可の手順 |
| 確定したとき | 許可が無いままパネルで確定+挿入キー(または確定+送信キー)を押したとき(文章が空のときは開きません)。パネルは閉じます | 「挿入できませんでした。」の囲みと、許可が無いこと、許可の手順 |

- 許可が無いときの表示は「アクセシビリティの許可がありません。」「TatakiNote が文章を入力欄に挿入するには許可が必要です。」です。ボタンは「閉じる」と「システム設定を開く」です。
- 案内のウィンドウは1枚だけです。開いたまま別の場面で開こうとしても増えず、表示が新しくなって手前に出ます。

## 許可の手順

許可が無いときは、案内の「許可の手順」に次の3つが出ます。

1. 下の「システム設定を開く」を押します。
2. 「プライバシーとセキュリティ」→「アクセシビリティ」で、TatakiNote のスイッチをオンにします。
3. 一覧に TatakiNote が無いときは、「+」を押して、アプリケーションフォルダの TatakiNote を追加します。

「システム設定を開く」を押すと、システム設定の「プライバシーとセキュリティ」→「アクセシビリティ」が開きます。

案内には「オンにすると、数秒のうちにこの画面の表示が変わります。」と出ています。オンにすると、案内のウィンドウは開いたまま、数秒のうちに「アクセシビリティの許可があります。」の表示に変わります。このとき、手順と「システム設定を開く」ボタンは消え、「閉じる」ボタンだけが残ります。

## 初めて起動したとき

初めて起動したときに許可が無いと、案内に「チュートリアルは、設定の「アプリ情報」からいつでも開けます。」が加わります。許可をオンにすると、案内は「アクセシビリティの許可があります。」と「続けて、TatakiNote の使い方を練習しましょう。」の表示に変わり、ボタンは「次へ」だけになります。この状態の案内は、`esc` やウィンドウの閉じるボタンでは閉じられません。「次へ」を押すと案内が閉じて、[チュートリアル](tutorial.md)が開きます。許可をオンにせずに「閉じる」で閉じることもできます。

## 確定で案内が開いたとき

許可が無いまま確定すると、案内の上に次の囲みが出ます。

> 挿入できませんでした。
>
> 書いた文章はパネルに下書きとして残っています。許可した後に、パネルを開いてもう一度確定してください。

1. [許可の手順](#許可の手順) で許可します。
2. 案内を「閉じる」で閉じます。
3. ホットキー `⌥⇧Space`(Option + Shift + Space。初期値。変え方は [ホットキーを変える](settings.md#ホットキーを変える))か、メニューバーの TatakiNote のアイコン →「パネルを開く」でパネルを開きます。書いた文章が下書きとして残っています。
4. もう一度、確定+挿入キーを押します。

## 案内を閉じる

- 「閉じる」ボタン・`esc`(Escape)・ウィンドウの閉じるボタンのどれでも閉じられます。
- `↩`(Return)には、どのボタンも割り当てていません。起動した直後に `↩` を押した拍子に、システム設定が開かないようにするためです。
- 閉じても TatakiNote は終了しません。メニューバーに常駐したまま動き続け、パネルも開けます。
- 案内を閉じている間は、許可の状態を確かめ直しません。案内はメニューから開き直せません。許可が無いまま確定するか、TatakiNote を起動し直したときに、開きます。
- 許可の状態は、案内を閉じた後も、設定の「アプリ情報」で確かめられます([許可の状態を確かめる](#許可の状態を確かめる))。

## 許可の状態を確かめる

設定ウィンドウのサイドバーの「アプリ情報」を選ぶと、「アクセシビリティの許可」に今の許可の状態が出ます([設定ウィンドウ](settings.md#アプリ情報の項目))。

- 許可があるときは、「アクセシビリティの許可があります。」と出ます。
- 許可が無いときは、許可が無いことと[許可の手順](#許可の手順)、「システム設定を開く」ボタンが出ます。ボタンを押すと、案内の「システム設定を開く」と同じく、システム設定のアクセシビリティが開きます。
- 表示している間にシステム設定で許可を変えると、開き直さなくても、数秒のうちに表示が変わります。
- 案内のウィンドウとは別の表示です。ここで許可の状態を見ても、案内は開きません。
- 案内の外観は、設定の「テーマ」に合わせます([テーマを選ぶ](settings.md#テーマを選ぶ))。
