# 入力欄を選んだらパネルを自動で出す

自動表示を使うと、他のアプリで入力欄をクリックするなどして選んだだけで、パネルが開きます。ホットキーを押す手間が省けます。
自動で開いたパネルは、ホットキーで開いたときと同じものです。挿入先も、パネルが開いた瞬間に前面だったアプリになります([挿入先の決まり方](insert-and-send.md#挿入先の決まり方))。

## 自動表示を使う

1. メニューバーの TatakiNote のアイコン →「設定」で設定ウィンドウを開きます(メニューが開いている間は `⌘,`(Command + カンマ)でも開けます)。
2. 「一般」の「自動表示」のラジオボタンから選びます。

| 選択肢 | 動き |
|---|---|
| 「オフ」(初期値) | 自動では開きません |
| 「全アプリ」 | どのアプリでも、入力欄を選ぶとパネルが開きます |
| 「選んだアプリのみ」 | 「対象のアプリ」の一覧にあるアプリだけで、入力欄を選ぶとパネルが開きます([対象のアプリを選ぶ](#対象のアプリを選ぶ)) |

- 設定画面の説明文は「入力欄を選んだだけでパネルを開きます。ホットキーは今までどおり使えます。」です。
- 自動表示には、アクセシビリティの許可が要ります。許可が無いと、自動では開きません([アクセシビリティの許可](accessibility.md))。
- 自動表示を使っていても、ホットキー `⌥⇧Space`(Option + Shift + Space。初期値)とメニューの「パネルを開く」は、そのまま使えます。ホットキーの変え方は [ホットキーを変える](settings.md#ホットキーを変える)。
- 選んだ値はその場で保存され、TatakiNote を起動し直しても残ります。

## 対象のアプリを選ぶ

「自動表示」が「選んだアプリのみ」のときに、パネルを出すアプリを「対象のアプリ」の一覧で選びます。アプリは複数選べます。「オフ」「全アプリ」のときは、一覧と「＋」「−」のボタンは押せません。

設定画面の説明文は「「＋」で起動中のアプリから追加します。起動していないアプリは「その他…」から選べます。」です。

### 起動中のアプリを足す

1. 「＋」を押します。起動中のアプリが名前順に並んだメニューが開きます。
2. 足したいアプリを選びます。一覧の末尾に入ります。

- すでに一覧にあるアプリと、TatakiNote 自身は、メニューに出ません。同じアプリは1つだけ出ます。
- 設定ウィンドウを開いた後に起動・終了したアプリも、メニューに反映されます。
- 起動中のアプリが残っていないときは、「その他…」だけが出ます。

### 起動していないアプリを足す

1. 「＋」→「その他…」を選びます。アプリケーションフォルダが開いた選択ダイアログが出ます。
2. アプリを1つ選びます。一覧に入ります。

- 選べるのはアプリだけです。一覧に入れられないアプリ(アプリの識別情報が無いもの)を選んだときは、何も足されず、エラーも出ません。
- すでに一覧にあるアプリを選んでも、一覧は変わりません。

### アプリを外す

一覧で行を選んで「−」を押します。行を選ぶまで「−」は押せません。外した後は選択が外れ、「−」はまた押せなくなります。

### 一覧の表示

- 各行には、アプリのアイコンと名前が出ます。
- 名前は、一覧に足したときの名前です。後からアプリの名前が変わっても変わりません。
- アプリが削除された・この Mac に入っていないときも、足したときの名前で出ます。アイコンは、点線の四角の絵になります。

### モードを変えたとき

- 「オフ」や「全アプリ」にしても、一覧の行は消えません。一覧と「＋」「−」が押せなくなるだけです。
- 「選んだアプリのみ」に戻すと、元の一覧がそのまま使われ、操作できるようになります。
- TatakiNote を起動し直しても、モードと一覧は残っています。

## 自動で出るときと出ないとき

| 状況 | 自動で出るか |
|---|---|
| 「自動表示」が「オフ」 | 出ません |
| アクセシビリティの許可が無い | 出ません |
| パネルがすでに開いている | 何も起きません(挿入先も変わりません) |
| 前面のアプリが TatakiNote 自身(設定ウィンドウなど) | 出ません |
| 「選んだアプリのみ」で、前面のアプリが一覧に無い | 出ません |
| 選ばれたものが入力欄でない・入力欄かどうか分からない | 出ません |
| 選ばれたものがパスワードの入力欄 | 出ません(クリックしても出ません) |
| 入力欄が選ばれた(クリック・`Tab` キー・ページやアプリが自分でカーソルを置いた) | 出ます(下の [続けて出ないようにする仕組み](#続けて出ないようにする仕組み) に当たらなければ) |
| 入力欄の枠の中をクリックした | 出ます(パネルを閉じた直後・同じ入力欄・アプリが前面になった直後でも) |
| 入力欄の外をクリックした・入力欄の枠が分からないアプリでクリックした | 出ません |

## 続けて出ないようにする仕組み

クリック以外で入力欄が選ばれたとき(`Tab` キーや、アプリが自分でカーソルを置いたとき)は、次の場合には出しません。閉じたパネルが勝手に出直したり、アプリを切り替えて戻っただけで出たりしないためです。

| 場合 | 内容 |
|---|---|
| アプリが前面になった直後 | 約 0.25 秒の間は出しません |
| パネルを閉じた直後 | 約 0.5 秒の間は出しません |
| 最後に自動で出したときと同じ入力欄 | 出しません。同じアプリの中で別のものに移ると、この決まりは解けます(入力欄で出して閉じ、別のものを選んでから戻ったときは出ます)。別のアプリに切り替えただけでは解けません |

入力欄の枠の中をクリックしたときは、これらに当たっても出ます(自分で入力欄を押したため)。

## 設定を変えたとき

- 「自動表示」や「対象のアプリ」を変えると、**次にアプリが前面になったところから**効きます。設定ウィンドウを開くと TatakiNote が前面になるので、閉じて相手のアプリに戻れば効きます。
- アクセシビリティの許可を与えたときも、次にアプリが前面になったところから効きます。

## 知っておくこと

- **閉じた後のクリックで出直す**: パネルを閉じた後、入力欄の枠の中をクリックするたびにパネルが出直します。`esc` で閉じて入力欄に直接書いている途中の、カーソルを動かすクリック・ドラッグ・ダブルクリックでも出ます。
- **対応していないアプリ**: アクセシビリティに対応していないアプリや、画面を独自に描いているアプリでは働きません。
- **Chrome や Electron のアプリ**: Google Chrome や、Electron で作られたアプリでは、前面になったときに、Web の中身をアクセシビリティの仕組みに出すよう頼みます。中身が用意されるまで少しかかるので、前面にした直後の1回目の入力欄を取りこぼすことがあります。
- **「全アプリ」での重さ**: 「全アプリ」では、前面になった Chrome や Electron のアプリすべてに、Web の中身を出すよう頼みます。そのアプリが重くなることがあります。「選んだアプリのみ」なら、自動表示から頼むのは選んだアプリだけです(パネルを開いたときは、モードに関係なく、挿入先のアプリにも頼みます)。一度頼んだ設定は、モードを変えても戻さず、そのアプリを終了すると消えます。
- **切り替えた直後に出ることがある**: Chrome や Electron のアプリが遅れて知らせてきたときや、別のアプリのウィンドウをクリックして戻ったときに、切り替えて戻っただけなのにパネルが出ることがあります。
- **応答しないアプリ**: 応答しないアプリが前面のとき、TatakiNote が最大で約 0.5 秒止まることがあります。
- **追加の許可は要らない**: クリックを見るのに、アクセシビリティの許可のほかに要る許可はありません。
