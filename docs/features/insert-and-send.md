# 書いた文章を挿入する・送信する

パネルで書いた文章は、確定+挿入キーを押すと、パネルを開いたときに使っていたアプリの入力欄に入ります(挿入)。
「確定+送信」のキーを割り当てると、挿入したあと、そのアプリで Enter を押したのと同じように送信まで行えます。

挿入と送信には、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。

ここに書いてあるのは、インサートモードの動きです。設定でノートモードにすると、挿入先を調べず、確定+挿入キー・確定+送信キーでも確定しません(`⇧⌘↩` と `⌘↩` は改行になります)。挿入先の表示と枠線も出ません。パネルで書いて下書きに保存するだけの使い方です([モードを切り替える](settings.md#モードを切り替える))。

## 挿入する

1. 文章を入れたいアプリ(テキストエディタやブラウザ、チャットアプリなど)を前面にして、入力欄にカーソルを置きます。
2. ホットキー `⌥⇧Space`(Option + Shift + Space。初期値。変え方は [ホットキーを変える](settings.md#ホットキーを変える))か、メニューバーの TatakiNote のアイコン →「パネルを開く」で、パネルを開きます。
3. 文章を書きます。`↩`(Return)は改行です。
4. 確定+挿入キー(初期値は `⇧⌘↩`(Shift + Command + Return))を押します。パネルが閉じ、手順 1 のアプリに文章が入ります。挿入だけで、送信はしません。挿入して送信までしたいときは、確定+送信キー(初期値は `⌘↩`(Command + Return))を使います([挿入して送信する](#挿入して送信する))。キーは設定で変えられます([「キー」の項目](settings.md#キーの項目))。

パネルの下の帯の「挿入」「送信」をクリックしても、同じ確定になります([パネルの下の帯](panel.md#パネルの下の帯))。

確定+挿入キーは挿入だけを行います。内容を確かめてから、挿入先で自分で Enter を押して送信します。

## 確定のキー

パネルには、キーを割り当てられる操作が2つあります。設定の記録ボックスで、修飾キー(⌘・⌥・⌃・⇧のいずれか)を含む好きなキーの組み合わせを登録します([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。

| 操作 | 何をするか | 初期値 |
|---|---|---|
| 確定+挿入 | 文章を挿入します | `⇧⌘↩`(Shift + Command + Return) |
| 確定+送信 | 文章を挿入したあと、挿入先で Enter を送ります([挿入して送信する](#挿入して送信する)) | `⌘↩`(Command + Return) |

- Return キーとテンキーの Enter キーは同じキーとして扱います。Caps Lock や fn キーの状態は関係ありません。`⌘J` のような、Return 以外のキーも登録できます。ただし `⌘K`・`⌘S`・`⌘N`・`⌘B`・`⌘,` はパネルの検索・保存・新規・サイドバーの開閉・設定のキーなので、登録できません([下書きと履歴](drafts-and-history.md#キーについて))。
- 同じキーは両方に登録できません。もう一方で使っているキーを登録しようとすると受け付けられず、理由が表示されます([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。
- キーの登録・変更は [「キー」の項目](settings.md#キーの項目) を見てください。変えると、パネルが開いていても次のキー入力から効きます。

### 設定ごとのキーの動き

初期値(確定+挿入は `⇧⌘↩`、確定+送信は `⌘↩`)のときの動きです。

| 押したキー | 動き |
|---|---|
| `⇧⌘↩`(Shift + Command + Return) | 確定+挿入(挿入だけ。Enter は送りません) |
| `⌘↩`(Command + Return) | 確定+送信(挿入して Enter を送信) |
| `⇧↩` / `↩`(Return) | 改行 |

- 確定+挿入キー・確定+送信キーのどちらにも登録していない Return 系のキー(`⇧↩`・`⌘↩`・`⇧⌘↩` など)は、修飾キーなしの `↩` と同じく改行になります。
- 日本語入力などで変換中(未確定の文字がある間)は、どのキーも入力メソッドの確定になり、パネルの確定にはなりません。
- 確定+挿入キーの登録を消すと、確定+挿入キーでは挿入できません(確定+送信キーでだけ挿入します)。確定+挿入キーと確定+送信キーの両方を登録なしにはできないので、最後の1つは消せません。挿入せずに書くだけで使うときは、ノートモードにします([モードを切り替える](settings.md#モードを切り替える))。

## 挿入して送信する

確定+送信キーを割り当てると、そのキーで、文章を挿入したあと、挿入先に修飾キーなしの Enter を1回送ります。チャットアプリなどでは、そのまま送信されます。

1. 送信したい入力欄のあるアプリ(チャットアプリなど)を前面にして、入力欄にカーソルを置きます。
2. パネルを開いて、文章を書きます。
3. 確定+送信キーを押します。パネルが閉じ、手順 1 のアプリに文章が入り、続けて Enter が送られます。

確定+挿入キーに「⌘J」、確定+送信キーに「⇧⌘↩」を登録したときの例:

| 押したキー | 結果 |
|---|---|
| `⌘J` | 確定+挿入(挿入だけ。Enter は送りません) |
| `⇧⌘↩` | 確定+送信(挿入して Enter を送ります) |
| `⇧↩` / `↩` | 改行 |

確定+挿入キーを登録していないときは、確定+送信キーでだけ挿入できます。

- **送信は取り消せません。** 挿入先の入力欄に元からあった文章も、Enter でまとめて送られます(挿入先のアプリの動きです)。
- 書いている途中の誤送信を防ぐのが TatakiNote の目的なので、送信するのは、自分でキーを登録して、そのキーを押したときだけにしています。
- 送る Enter に、確定+送信キーで押した `⇧` や `⌘` が混ざらないよう、押している修飾キーが離れるのを待ってから送ります(約 0.5 秒待っても離れないときは、そのまま修飾キーなしで送ります)。
- 送る直前に、前面のアプリが挿入先でなくなっていたら、Enter を送りません。たとえば `⇧⌘↩` の `⌘` を押したまま、`⌘Tab` で別のアプリに切り替えたときです。文章は挿入先に入っていて、Enter を送らなかったことの知らせは出ません。
- 変換中に確定+送信キーを押しても、入力メソッドの確定になるだけで、挿入も送信もされません。
- 文章が空のまま押すと、パネルは閉じずに横に揺れるだけで、挿入も送信もされません。
- 挿入できなかったときは、Enter も送りません([確定したときの動き](#確定したときの動き))。

## 確定したときの動き

確定+挿入(または確定+送信)したときの動きは、次のどれかになります。

| 状況 | 動き | 書いた文章 |
|---|---|---|
| 文章が空 | パネルは閉じずに、横に揺れます。挿入はしません。案内は出ません | 空のまま |
| アクセシビリティの許可が無い | パネルが閉じ、「アクセシビリティの許可」の案内が開きます([確定で案内が開いたとき](accessibility.md#確定で案内が開いたとき))。挿入はしません | パネルに残ります |
| 挿入先が「挿入先なし」 | パネルは閉じません。タイトルバーの「挿入先なし」が揺れてオレンジ色に光ります。挿入はしません | パネルに残ります |
| 挿入先のアプリを前面にできなかった(約1秒待っても前面にならなかった・アプリが終了していた) | パネルは閉じません。その入力欄は挿入先ではなくなり、「挿入先なし」が揺れてオレンジ色に光ります。貼り付けはせず、クリップボードにも触れません | パネルに残ります |
| 挿入先で入力欄が選ばれていなかった(ボタン・一覧・Web ページの本文などが選ばれていた) | 上の行と同じです | パネルに残ります |
| 挿入できた | パネルが閉じ、挿入先に文章が入り、クリップボードは元の内容に戻ります。パネルがあった場所に、トーストが出ます([挿入できたときのトースト](#挿入できたときのトースト))。文章は[履歴](drafts-and-history.md#挿入したときの履歴)に残ります | パネルは空になります |

- 挿入先があるときは、パネルを閉じる前に、挿入先のアプリを前面にして入力欄が選ばれているかを確かめます。確かめでだめだったときは、パネルを閉じないので、そのまま入力欄をクリックして挿入先を選び直せます([挿入先を選び直す](#挿入先を選び直す))。
- 確かめの後、貼り付けまでの間に挿入できなかったときは、パネルが開き直り、文章が戻って、「挿入先なし」が光ります。その間にパネルで新しい文章を書き始めていたときは、確定した文章はパネルに戻せません(新しい文章が残ります)。

- 挿入できたときは、ドラッグで変えていたパネルの大きさも元に戻ります(次に開くときは既定の大きさ。初期値は 520 × 340 ポイント)。挿入できなかったときは、変えた大きさが保たれます(空のまま確定したときは、パネルが閉じないので大きさもそのままです。[パネルの大きさ](panel.md#パネルの大きさ))。
- 入力欄かどうかは、アクセシビリティの仕組みで調べます。入力欄かどうか分からないアプリ(アクセシビリティに対応していないアプリなど)は、入力欄がないものとして扱うので、「挿入先なし」になり、挿入できません。Finder(デスクトップを含む)も、名前の変更の欄などの入力欄が選ばれているとき以外は同じです。
- 確定+送信でも、分かれ方は同じです。挿入できなかったときは Enter を送りません。
- パネルに残った・戻った文章は、パネルを開けばそのまま残っています。原因を直してから、もう一度確定してください。保存した下書きから確定したときは、同じ下書きを開いた状態に戻ります([下書きと履歴](drafts-and-history.md))。

### 挿入できたときのトースト

挿入できると、パネルがあった場所の中央に、丸いカプセルの形の小さなトーストが約 1.9 秒出て消えます。文は「Safari に挿入しました」のように挿入先のアプリの名前が入り、確定+送信のときは「Safari に送信しました」になります。アプリの名前が分からないときは「挿入しました」「送信しました」です。

- トーストは、クリックを受け付けず、使っていたアプリは前面のままです。クリックは下のアプリに届きます。
- 出ている間にパネルを開くと、トーストはすぐ消えます。
- 挿入できなかったとき・空のまま確定したときは、出ません。

## 挿入先の決まり方

挿入先は、「今確定したら文章が入る入力欄」です。パネルを開いている間、確定する前から確かめられます。

- パネルを**閉じた状態から開いた瞬間**に前面だったアプリで、入力欄が選ばれていれば、そのアプリが挿入先です。自動表示で開いたときも同じです。
- そのとき TatakiNote 自身が前面だった(設定ウィンドウを開いていたときなど)ときは、最後に前面になった TatakiNote 以外のアプリになります。TatakiNote を起動したときから覚え始めます。
- 前面のアプリが無いとき、入力欄が選ばれていないとき、入力欄かどうか分からないときは、「挿入先なし」になります。
- 開いている間は、挿入先は開いたときの入力欄(または[クリックで選び直した](#挿入先を選び直す)入力欄)のままです。`Tab` などでアプリの中のフォーカスが移っても、挿入先は変わりません。入力欄の位置を見続けるだけで、枠線が入力欄に付いて動きます。入力欄が使えなくなったとき(位置が分からなくなったとき)と、挿入先のアプリが終了したときは「挿入先なし」になります。
- 開いたままメニューの「パネルを開く」を選び直しても、挿入先は変わりません(見張りは続きます)。

## 挿入先を見分ける

挿入先は、次の2か所で分かります。

- **タイトルバーの右端**: 挿入先があるときは、そのアプリのアイコン。ないときは「挿入先なし」。マウスを乗せると、「このまま確定しても挿入しません。入れたい入力欄をクリックすると、そこが挿入先になります」と出ます([パネルのタイトルバー](drafts-and-history.md#パネルのタイトルバー))。
- **入力欄を囲む枠線**: 挿入先の入力欄が、他のアプリの上に重ねた枠線で囲まれます。枠線はクリックを受け付けないので、入力欄はこれまでどおり操作できます。入力欄やウィンドウを動かしたり、スクロールしたりすると、枠線も追いかけます。入力欄が他のウィンドウに少しでも隠れたとき、画面の外へ出たときは、枠線を消し、表に出ると出します。パネルを閉じても消えます。

枠線は、設定の「パネル」の「挿入先の枠線」でオフにできます([パネルの項目](settings.md#パネルの項目))。オフにしても、タイトルバーの表示と、確定したときの動きは変わりません。

- 枠線を出すには、入力欄の位置が分かる必要があります。位置を教えてくれないアプリでは、挿入先にはなっても枠線は出ません。
- チュートリアルの練習用のチャットが挿入先のときは、アイコンだけを出し、枠線は出しません。

## 挿入先を選び直す

パネルを開いたまま、文章を入れたい別のアプリの入力欄をクリックすると、そこが新しい挿入先になります。閉じて開き直す必要はありません。

- クリックしたアプリは前面のままで、パネルにはキー入力が戻るので、続けてパネルに書けます。
- 同じアプリの中の別の入力欄をクリックしたときも、同じです。
- 入力欄ではない場所(ボタンやタイトルバーなど)をクリックしたときは、挿入先は移りません。挿入先のアプリの入力欄以外をクリックしたときは、「挿入先なし」になります。このときのキー入力は、クリックしたアプリに届きます。パネルに戻るには、パネルをクリックします。
- TatakiNote 自身のウィンドウ(チュートリアル・設定)をクリックしても、挿入先は変わりません。
- 確定で挿入できなかった入力欄や、「挿入先なし」になったあとは、入力欄をクリックして選び直すまで、挿入先に戻りません。`Tab` などでフォーカスが移っただけでは戻りません。

## クリップボードの扱い

挿入は、クリップボードに文章を入れて `⌘V`(Command + V)を送る方法で行います。コピーしていた内容は、挿入の後に元に戻ります。

- 挿入している間、クリップボードには一時的に、挿入する文章だけが入ります。
- クリップボード履歴アプリには、一時的な内容だという印を付けて渡します。履歴に残さないかどうかは、履歴アプリ次第です。
- `⌘V` を送った約 0.5 秒後に、元のクリップボードを、すべての項目・すべてのデータの種類(画像・リッチテキストなどを含む)ごと元に戻します。確定+送信のときは、Enter を送った後に戻します。
- その間に自分や他のアプリが何かをコピーしていたら、その内容を上書きしません(元に戻しません)。
- 中身をその場で取り出せない種類のデータ(提供元のアプリが後から渡す約束だけをしているデータなど)は、元に戻らないことがあります。
- 続けて確定して挿入が重なったときは、前の挿入でクリップボードを元に戻し終えてから、次の挿入を始めます。
