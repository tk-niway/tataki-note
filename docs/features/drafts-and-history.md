# 下書きと履歴

パネルで書いた文章を「下書き」として取っておき、あとで呼び戻せます。挿入できた文章は「履歴」に残り、見返して使い回せます。下書きと履歴は、パネルの左に開くサイドバーで探します。

保存していない文章は「書きかけ」と呼びます([書きかけ](panel.md#書きかけ))。「下書き」は、`⌘S` で保存したものだけを指します。

## パネルのタイトルバー

パネルの上のバーには、次のボタンが並びます。

| 位置 | ボタン | 動き |
|---|---|---|
| 左端 | 閉じるボタン(×) | パネルを閉じます。書いた文章は残ります |
| 左 | サイドバーの開閉ボタン | サイドバーを開く・閉じる。`⌘B` と同じ。マウスを乗せると「下書きと履歴(⌘B で開閉、⌘K で検索)」と出ます |
| 右 | 新規作成のアイコン | 新しい書きかけにします(`⌘N` と同じ) |
| 右 | 保存のアイコン | 今の文章を下書きに保存します(`⌘S` と同じ) |
| 右端 | 「挿入先」とアプリのアイコン、または「挿入先なし」 | 確定したときに文章が入るアプリを示します |

- 保存のアイコンは、パネルが空のときは押せません。新規作成のアイコンは、空の新しい書きかけを出しているときは押せません。
- 「挿入先」には、文章が入る入力欄があるアプリのアイコンが出ます。アイコンにマウスを乗せると「Safari に挿入します」のように、アプリの名前が出ます。挿入先が分からないときは、「挿入先なし」と出て、マウスを乗せると「このまま確定しても挿入しません。入れたい入力欄をクリックすると、そこが挿入先になります」と出ます。開いている間も、選ばれている入力欄に合わせて変わります。挿入先の決まり方は [挿入先の決まり方](insert-and-send.md#挿入先の決まり方)。

## 下書きに保存する

1. パネルに文章を書きます。
2. `⌘S`(Command + S)か、タイトルバーの保存のアイコンを押します。

- 保存した下書きは、サイドバーの「下書き」の先頭に並びます。パネルの文章はそのまま残り、その下書きを開いている状態になります。
- 下書きを開いている間は、文章を書き換えると、`⌘S` を押さなくても自動でその下書きに上書きされます。開いている下書きで `⌘S` を押すと、いまの内容を確実に書き出し、保存のアイコンが一瞬チェックの印に変わります。
- 書き換えた下書きは、一覧の先頭に移ります。一覧は、新しく保存・書き換えたものが上です。
- 下書きは TatakiNote を終了しても残ります。この Mac の中にファイルとして残り、通信はしません。
- 保存したときは、新しい下書きの行がサイドバーに現れる動きが、1 秒たたずに終わります(サイドバーが閉じているときは、文章が開閉ボタンに吸い込まれます)。動きの間も、そのまま書き続けられます。

## 新しい書きかけにする

`⌘N`(Command + N)か、新規作成のアイコンを押すと、パネルが空の新しい書きかけになります。

- 保存していない文章があるときは、先に確認が出ます([保存していない文章があるとき](#保存していない文章があるとき))。下書きを開いているときは、確認なしで切り替わります(下書きには、書いた内容がすでに残っています)。
- パネルが空の書きかけのときは、何も起こりません。

## サイドバーで探して呼び出す

サイドバーは、パネルの中の左側に出る一覧です。開閉ボタンか `⌘B`(Command + B)で開閉します。`⌘K`(Command + K)でも開きます(検索欄に移ります)。

- 開くと、パネルが左へ広がり、サイドバーが文章の部分の後ろから滑り出てきます。閉じると、滑り込んで元の幅に戻ります。設定の「パネルの開閉エフェクト」がオフのときは、動きなしですぐに開閉します([アニメーションを切り替える](settings.md#アニメーションを切り替える))。画面の左端で入らないときは、パネルが右へずれて開きます。
- パネルの大きさをドラッグで変えたときの大きさは、サイドバーを除いた文章の部分の大きさです。設定の「今のパネルの大きさを既定にする」で既定にする大きさも同じです([パネルの大きさ](panel.md#パネルの大きさ))。
- サイドバーを開いていたか・「下書き」「履歴」のどちらを見ていたかは、次にパネルを開いたときも覚えています。
- サイドバーを開いても、使っていたアプリは前面のままです。
- サイドバーの左下の歯車のボタン(`⌘,` と同じ)を押すと、パネルを閉じて(書いた文章は残ります)、[設定ウィンドウ](settings.md)を開きます。

### 下書きと履歴を切り替える

サイドバーの上のアイコンで、「下書き」と「履歴」を切り替えます。

| 側 | 行に出るもの |
|---|---|
| 「下書き」 | 文章の最初の行(先頭の空行は飛ばします)。文章が空のときは「(空の下書き)」 |
| 「履歴」 | 「10月6日 14:32 · Safari」のように、挿入した日時と挿入先のアプリの名前(分からないときは「不明なアプリ」)と、文章の最初の行 |

- パネルに出している下書きの行には印が付きます。
- 空のときは説明が出ます。「下書き」は「⌘S で今の文章を取っておけます」、「履歴」は「挿入した文章がここに残ります(最新 50 件)」です。

### 検索する

`⌘K` を押すと、サイドバーが開いて検索欄に移ります(「下書きを検索」「履歴を検索」)。文字を打つと、見ている側の一覧が絞り込まれます。

- 文章の全体から探します。2 行目以降の語でも当たります。
- 英字の大文字・小文字と、全角・半角は区別しません。濁点の有無(「は」と「ば」)は区別します。
- 当たるものが無いときは「「(入力した文字)」に一致するものはありません」と出ます。
- 日本語を変換している間は、`↑` `↓` `↩` `esc` は入力メソッドの操作になります。

| キー | 動き |
|---|---|
| `↑` / `↓` | 選んでいる行を動かします |
| `↩` | 選んでいる行を呼び出し、パネルの入力欄に戻ります |
| `esc` | 入力欄に戻ります(パネルは閉じません) |
| `⌘⌫`(Command + Delete) | 選んでいる行を削除します([削除する](#削除する)) |

- 行をクリックしても呼び出せます。
- 下書きを呼び出すと、その下書きを開いている状態になります。履歴の行を呼び出すと、その文章の写しがパネルに入り、書きかけとして扱われます(履歴そのものは変わりません)。書き換えて、`⌘S` で下書きにもできます。
- 保存していない文章があるときに呼び出すと、先に確認が出ます。

## 保存していない文章があるとき

保存していない文章(書きかけ・履歴から入れた文章)があるまま、`⌘N` を押したり、別の下書き・履歴を呼び出したりすると、パネルの中に確認が出ます。

「保存していない文章があります。下書きに保存しますか?」

| ボタン | キー | 動き |
|---|---|---|
| 「保存」 | `↩` | 今の文章を下書きに保存してから切り替えます |
| 「保存しない」 | `⌘D` | 今の文章を捨てて切り替えます |
| 「キャンセル」 | `esc` | 切り替えず、文章もそのままです |

確認が出ている間は、確定のキーや文字の入力は効きません。パネルを閉じたときは、「キャンセル」と同じになります。

## 削除する

行を右クリックして「削除」を選ぶか、行を選んで `⌘⌫` を押します。行にゴミ箱のボタンはありません。

- 下書きは、確認が出ます。「この下書きを削除しますか?」に、「削除」(または `↩`)かと「キャンセル」(または `esc`)で答えます。検索欄の文字を変えると、確認は取り消されます。
- 履歴は、確認なしですぐ消えます。
- パネルに出している下書きを削除したときは、パネルの文章は残り、保存していない書きかけになります。

履歴をまとめて消すには、設定の「一般」の「履歴をすべて削除」を使います([履歴をすべて削除する](settings.md#履歴をすべて削除する))。

## 挿入したときの履歴

挿入に成功した文章は、挿入日時と挿入先のアプリの名前と一緒に履歴に残ります。

- 履歴は最新の 50 件までです。51 件目からは、古いものから消えます。
- 挿入できなかったとき・文章が空のまま確定したときは、履歴に残りません。チュートリアルの練習用のチャットへの挿入も残りません([チュートリアル](tutorial.md))。
- 下書きを開いたまま挿入できたときは、下書きはそのまま残り、パネルは空の新しい書きかけになります。挿入できずに文章がパネルに戻ったときは、同じ下書きを開いた状態に戻ります([確定したときの動き](insert-and-send.md#確定したときの動き))。
- 履歴は、この Mac の中にファイルとして残り、TatakiNote を終了しても消えません。

## 保存できなかったとき

サイドバーに、次の説明が出ることがあります。

| 説明 | 意味 |
|---|---|
| 「保存できませんでした。ディスクの空きを確かめてください。」 | 下書きか履歴をファイルに書き出せませんでした。表示している内容はそのまま使えます。書き出せるようになると、説明は消えます |
| 「保存してあった下書きを読み込めませんでした。元のファイルは別名で残してあります。」 | 起動したときに、保存してあった下書きが読めませんでした。空の一覧で始まります |
| 「挿入の履歴を読み込めませんでした。元のファイルは別名で残してあります。」 | 起動したときに、履歴が読めませんでした。空の一覧で始まります |

## キーについて

`⌘K`・`⌘S`・`⌘N`・`⌘B`・`⌘,` は、パネルで使うキーなので、確定+挿入キー・確定+送信キー・「パネルを開く・閉じる」には登録できません([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。これらのキーが登録されていたときは、起動したときに初期値に戻ります(知らせは出ません)。
