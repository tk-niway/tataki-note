# 下書きと履歴

パネルで書いた文章を「下書き」として取っておき、あとで呼び戻せます。挿入できた文章は「履歴」に残り、見返して使い回せます。下書きと履歴は、パネルの左に開くサイドバーで探します。

保存していない文章は「書きかけ」と呼びます([書きかけ](panel.md#書きかけ))。「下書き」は、`⌘S` で保存したものだけを指します。

## パネルのタイトルバー

パネルの上のバーには、次のボタンが並びます。

| 位置 | ボタン | 動き |
|---|---|---|
| 左端 | 閉じるボタン(×) | パネルを閉じます。書いた文章は残ります。マウスを乗せると赤くなります |
| 左 | サイドバーの開閉ボタン | サイドバーを開く・閉じる。`⌘B` と同じ。マウスを乗せると「下書きと履歴(⌘B で開閉、⌘K で検索)」と出ます |
| 右 | 新規作成のアイコン | 新しい書きかけにします(`⌘N` と同じ) |
| 右 | 保存のアイコン | 今の文章を下書きに保存します(`⌘S` と同じ) |
| 右 | 共有のアイコン | 今の文章で macOS のシェアのメニューを開きます([共有する](#共有する))。マウスを乗せると「共有」と出ます |
| 右端 | 「挿入先」とアプリのアイコン、または「挿入先なし」(インサートの書きかけ) | 確定したときに文章が入るアプリを示します |
| 右端 | 「ノート」(ノートの書きかけ) | 押すとインサートに戻ります([書きかけのモード](panel.md#書きかけのモード)) |

- パネルが空のときに保存のアイコンを押す(`⌘S` も同じ)と、パネルが横に揺れて、保存する文章が無いことを知らせます(設定の「アニメーション」がオフのときは、揺れずに警告音が鳴ります)。
- ボタンにマウスを乗せると、薄い背景が付きます。
- ノートの書きかけでは、右端の「挿入先」の表示は出ず、同じ場所に「ノート」が出ます。
- 「挿入先」には、文章が入る入力欄があるアプリのアイコンが出ます。アイコンにマウスを乗せると「Safari に挿入します」のように、アプリの名前が出ます。挿入先が分からないときは、「挿入先なし」と出て、マウスを乗せると「このまま確定しても挿入しません。入れたい入力欄をクリックすると、そこが挿入先になります」と出ます。開いている間は、入力欄をクリックして選び直したときに変わります。挿入先の決まり方は [挿入先の決まり方](insert-and-send.md#挿入先の決まり方)。

## 下書きに保存する

1. パネルに文章を書きます。
2. `⌘S`(Command + S)か、タイトルバーの保存のアイコンを押します。

- 保存した下書きは、サイドバーの「下書き」の先頭に並びます。パネルの文章はそのまま残り、その下書きを開いている状態になります。
- 下書きを開いている間は、文章を書き換えると、`⌘S` を押さなくても自動でその下書きに上書きされます。開いている下書きで `⌘S` を押すと、いまの内容を確実に書き出します。
- 書き換えた下書きは、一覧の先頭に移ります。一覧は、新しく保存・書き換えたものが上です。
- 下書きは TatakiNote を終了しても残ります。この Mac の中にファイルとして残ります。
- `⌘S`・保存のアイコンで保存すると、保存した文章の写しがパネルから飛んで、保存先に着いて弾みます。保存先は、サイドバーが閉じているときは開閉ボタン、開いて「下書き」を見ていて保存した下書きの行が一覧に出ているときはその行(着くと行が一瞬光ります)、それ以外は「下書き」の切り替えです。サイドバーが「履歴」を見ているときは、先に「下書き」に切り替わります。着くと、パネルの下側の中央に「下書きに保存しました」と出て、約 2 秒で消えます。動きの間も、そのまま書き続けられます。
- 開いている下書きを `⌘S`・保存のアイコンで上書き保存したときは、写しの動きは同じですが、「下書きに保存しました」とは出ません。
- 設定の「アニメーション」がオフのときは、写しは飛ばず、弾みもしません。代わりに「下書きに保存しました」が出ます(上書き保存でも出ます)。保存した下書きの行が見えているときは、薄れずに少しの間だけ色が付いて消えます。

## ファイルに書き出す

`⇧⌘S`(Shift + Command + S)を押すと、パネルの文章をテキストファイルとして書き出せます。

1. `⇧⌘S` を押すと、保存先を選ぶウィンドウが開きます。名前の欄は「untitled」で、最初に開くフォルダは前回書き出したフォルダです(初めてのときや、そのフォルダが無いときは「書類」)。
2. 名前とフォルダを決めて保存します。拡張子を付けなければ「.txt」が付きます。文字コードは UTF-8 です。
3. 書き出せると、パネルの下側の中央に「書き出しました」と出て、カーソルが入力欄に戻ります。

- パネルが空、または空白・改行だけのときは、ウィンドウは開かず、パネルが横に揺れて「書き出す文章がありません」と出ます(設定の「アニメーション」がオフのときは、揺れずに警告音が鳴ります)。
- 保存先を選ぶウィンドウを閉じる(キャンセルする)と、何も書き出さず、カーソルが入力欄に戻ります。ウィンドウが開いている間に `⇧⌘S` をもう一度押すと、開いているウィンドウが前に出ます。
- 書き出せなかったときは、「書き出せませんでした」と理由の警告が出ます。「OK」を押すと閉じます。
- サイドバーの行を右クリックして「ファイルに書き出す」を選ぶと、その行の文章を同じように書き出せます(パネルの文章は変わりません)。文章が空、または空白・改行だけの行では、この項目は選べません。

## 共有する

タイトルバーの共有のアイコンを押すと、パネルの文章で macOS のシェアのメニューが開きます。メッセージやメールなど、メニューに出るものへ文章を送れます。

- パネルが空、または空白・改行だけのときは、パネルが横に揺れて「共有する文章がありません」と出ます。
- サイドバーの行を右クリックして「共有」を選ぶと、その行の文章を共有できます(メニューは、マウスのある所に出ます)。文章が空、または空白・改行だけの行では、この項目は選べません。

## 新しい書きかけにする

`⌘N`(Command + N)か、新規作成のアイコンを押すと、パネルが空の新しい書きかけになります。

- 書きかけがあるときは、確認なしで切り替わり、その書きかけは「履歴」に残ります([書きかけは履歴に残る](#書きかけは履歴に残る))。下書きを開いているときは、そのまま切り替わります(下書きには、書いた内容がすでに残っています)。
- パネルが空の書きかけのときも、書きかけのモードは設定の「モード」で選んだモードに戻ります([書きかけのモード](panel.md#書きかけのモード))。

## サイドバーで探して呼び出す

サイドバーは、パネルの中の左側に出る一覧です。開閉ボタンか `⌘B`(Command + B)で開閉します。`⌘K`(Command + K)でも開きます(検索欄に移ります)。

- 開くと、パネルが左へ広がり、サイドバーが文章の部分の後ろから滑り出てきます。閉じると、滑り込んで元の幅に戻ります。設定の「アニメーション」がオフのときは、動きなしですぐに開閉します([アニメーションを切り替える](settings.md#アニメーションを切り替える))。画面の左端で入らないときは、パネルが右へずれて開きます。
- パネルの大きさをドラッグで変えたときの大きさは、サイドバーを除いた文章の部分の大きさです。設定の「今のパネルサイズを既定にする」で既定にする大きさも同じです([パネルの大きさ](panel.md#パネルの大きさ))。
- サイドバーを開いていたか・「下書き」「履歴」のどちらを見ていたかは、次にパネルを開いたときも覚えています。
- サイドバーを開いても、使っていたアプリは前面のままです。
- `⌘B` や開閉ボタンでサイドバーを開くと、カーソルは一覧に移ります。閉じると入力欄に戻ります。サイドバーを開いたままパネルを閉じて開き直したときは、入力欄から始まります。
- サイドバーの左下の歯車と「設定」のボタン(`⌘,` と同じ)を押すと、パネルを開いたまま、[設定ウィンドウ](settings.md)を開きます。設定ウィンドウを閉じると、キー入力はパネルに戻ります。

### 下書きと履歴を切り替える

サイドバーの上の「下書き」「履歴」の切り替えで、見る側を選びます。それぞれの名前の右に、その側の全件の数が出ます(検索で絞り込んでも変わりません)。見ている側は、アクセントカラーで塗られ、文字が白くなるので、どちらを見ているかが分かります。

| 側 | 行に出るもの |
|---|---|
| 「下書き」 | 1段目に文章の最初の行(先頭の空行は飛ばします。文章が空や空白・改行だけのときは「(空の下書き)」)。2段目に更新した日時と、2行目以降の本文の続き |
| 「履歴」 | 1段目に文章の最初の行。2段目に「10/6 14:32 · Safari」のように、挿入した日時と挿入先のアプリの名前(分からないときは「不明なアプリ」)と、本文の続き。挿入していない書きかけ([書きかけは履歴に残る](#書きかけは履歴に残る))は、日時と本文の続きだけで、アプリの名前は出ません |

- 日時は、今年なら「10/18 14:32」、それ以外の年は「2026/10/18 14:32」のように年も付きます。
- 本文の続きは、2行目以降の空でない行を半角スペースでつないだもので、行の幅に入らない分は「…」で省かれます。2行目以降が無い文章では出ません。

- パネルに出している下書き・履歴の行が、一覧のハイライトになります。
- 空のときは説明が出ます。「下書き」は「⌘S で今の文章を取っておけます」、「履歴」は「挿入した文章がここに残ります(最新 200 件)」です。件数は、設定で決めた履歴の件数になります([履歴に残す件数を変える](settings.md#履歴に残す件数を変える))。

### 一覧をキーボードで操作する

一覧にカーソルがあるときは、キーボードだけで行を行き来できます。`↑` `↓` で動かすと、その行の中身がすぐパネルに出ます。呼び出すための操作は要りません。

| キー | 動き |
|---|---|
| `↑` / `↓` | 前 / 次の行に動かし、その中身をパネルに出します。端で止まります |
| `→` / `↩` | 入力欄に移ります(パネルに出ていない行をハイライトしているときは、その中身を出してから) |
| `Tab` / `⇧Tab` | 「下書き」と「履歴」を切り替えます |
| `←` | 何も起きません |
| `esc` | パネルを閉じます(書いた文章は残ります) |
| `⌘⌫`(Command + Delete) | ハイライトしている行を削除します([削除する](#削除する))。ハイライトが無いときは何も消えません |
| 確定のキー・確定+送信のキー | 入力欄にいるときと同じく、パネルの文章を確定します([書いた文章を挿入する・送信する](insert-and-send.md))。ノートの書きかけでは何も起きません |

- 日本語を変換している間は、これらのキーは入力メソッドの操作になります。
- 行をクリックしたときも、`↑` `↓` で動かしたときと同じように中身がパネルに出て、カーソルは一覧に残ります。続けて書くときは、`→` `↩` か `⌘B`(サイドバーも閉じます)で入力欄に移ります。
- 一覧を行き来しても、書きかけは失われません。別の行を出すたびに、書きかけは「履歴」に残ります([書きかけは履歴に残る](#書きかけは履歴に残る))。

### 検索する

`⌘K` を押すと、サイドバーが開いて検索欄に移ります(「下書きを検索」「履歴を検索」)。文字を打つと、見ている側の一覧が絞り込まれます。

- 文章の全体から探します。2 行目以降の語でも当たります。
- 英字の大文字・小文字と、全角・半角は区別しません。濁点の有無(「は」と「ば」)は区別します。
- 当たるものが無いときは「「(入力した文字)」に一致するものはありません」と出ます。
- 日本語を変換している間は、`↑` `↓` `↩` `esc` は入力メソッドの操作になります。

| キー | 動き |
|---|---|
| `↑` / `↓` | 前 / 次の行に動かし、その中身をパネルに出します |
| `↩` | ハイライトしている行をパネルに出して、入力欄に戻ります。検索語が空で、パネルに出ている行も無いときは、何も出さずに入力欄に戻ります |
| `esc` | 入力欄に戻ります(パネルは閉じません) |

- 検索語を打つと、パネルに出ている行が絞り込んだ一覧にあればその行が、無ければ先頭の行がハイライトされます。`↩` でそれを出せます。
- 検索欄では `⌘⌫` で行は消えません。行を消すときは一覧で操作します([削除する](#削除する))。
- 行をクリックしても中身が出ます([一覧をキーボードで操作する](#一覧をキーボードで操作する))。
- 下書きを出すと、その下書きを開いている状態になります。履歴の行を出すと、その文章の写しがパネルに入ります(履歴そのものは変わりません)。履歴の写しを書き換えると書きかけになり、`⌘S` で下書きにもできます。書き換えていなければ、別の行を出しても履歴は増えません。

## 書きかけは履歴に残る

書きかけ(保存していない文章)があるまま、別の下書き・履歴を出したり、`⌘N` で新しい書きかけにしたりすると、確認は出ず、その時点で書きかけが「履歴」に残ります。パネルの下側の中央に「書きかけを履歴に残しました」と出ます。

- 挿入していない文章なので、行にはアプリの名前が出ません([下書きと履歴を切り替える](#下書きと履歴を切り替える))。
- 次のものは履歴に残りません: 空白だけの文章、開いた履歴から書き換えていない文章、下書きを開いているときの文章(書き換えは自動で下書きに保存されています)。
- パネルを閉じても、書きかけは履歴へは移らず、パネルに残ります。TatakiNote を終了したときに、書きかけがあれば履歴に残ります。
- 履歴に残した書きかけは、挿入した文章と同じ上限で数えます([挿入したときの履歴](#挿入したときの履歴))。

## 削除する

行を右クリックして(「ファイルに書き出す」「共有」と並ぶ)「削除」を選ぶか、一覧でハイライトしている行に `⌘⌫` を押します。行にゴミ箱のボタンはありません。

- 下書きも履歴も、確認なしですぐ消えます。元に戻すことはできません。
- 一覧の `⌘⌫` で消えるのは、ハイライトしている行です(ふだんはパネルに出ている行。検索語を打っているときは、パネルに出ていない先頭の行のこともあります)。ハイライトしている行が無いときは、何も消えません。
- パネルに出している下書きを削除したときは、パネルの文章は残り、保存していない書きかけになります。

履歴をまとめて消すには、設定の「一般」の「履歴をすべて削除」を使います([履歴をすべて削除する](settings.md#履歴をすべて削除する))。

## 挿入したときの履歴

挿入に成功した文章は、挿入日時と挿入先のアプリの名前と一緒に履歴に残ります。

- 履歴は、初期値では最新の 200 件までです。上限を超えると、古いものから消えます。件数は設定で変えられます([履歴に残す件数を変える](settings.md#履歴に残す件数を変える))。挿入していない書きかけも、同じ上限で数えます。
- 挿入できなかったとき・文章が空のまま確定したときは、履歴に残りません。チュートリアルの練習用のチャットへの挿入も残りません([チュートリアル](tutorial.md))。
- 下書きを開いたまま挿入できたときは、下書きはそのまま残り、パネルは空の新しい書きかけになります。挿入できずに文章がパネルに戻ったときは、同じ下書きを開いた状態に戻ります([確定したときの動き](insert-and-send.md#確定したときの動き))。
- パスワード欄に挿入した文章は、履歴に残りません。
- 履歴を残す期間を決めると、その期間を過ぎた履歴は消えます(初期値は無期限)。⌘S で保存した下書きは消えません([履歴を残す期間を変える](settings.md#履歴を残す期間を変える))。
- 履歴は、この Mac の中にファイルとして残り、TatakiNote を終了しても消えません。

## 保存できなかったとき

サイドバーに、次の説明が出ることがあります。

| 説明 | 意味 |
|---|---|
| 「保存できませんでした。ディスクの空きを確かめてください。」 | 下書きか履歴をファイルに書き出せませんでした。表示している内容はそのまま使えます。書き出せるようになると、説明は消えます |
| 「保存してあった下書きを読み込めませんでした。元のファイルは別名で残してあります。」 | 起動したときに、保存してあった下書きが読めませんでした。空の一覧で始まります |
| 「挿入の履歴を読み込めませんでした。元のファイルは別名で残してあります。」 | 起動したときに、履歴が読めませんでした。空の一覧で始まります |

## キーについて

`⌘K`・`⌘S`・`⌘N`・`⌘E`・`⌘B`・`⌘,`・`⇧⌘S` は、パネルで使うキーなので、確定+挿入キー・確定+送信キー・「パネルを開く・閉じる」には登録できません([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。これらのキーが登録されていたときは、起動したときに初期値に戻ります(知らせは出ません)。
