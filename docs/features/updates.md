# アップデートとインストール

TatakiNote は、1日に1回、新しい版があるかを自動で確かめます。新しい版があるときは、印でお知らせします。入れ替えるのは、利用者が選んだときだけです。
インストールは、配布している DMG から行います。

## インストールする

1. 前の版の TatakiNote を使っているときは、先にメニューバーの TatakiNote から「終了」を選びます。
2. Releases から最新の `TatakiNote-<版>.dmg` をダウンロードして開きます。
3. 開いた窓で、TatakiNote のアイコンを「アプリケーション」フォルダへドラッグします。
4. 「アプリケーション」フォルダの TatakiNote を開きます。初めて開くときは「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか?」と出るので、「開く」を押します。

起動するとメニューバーに現れます。アクセシビリティの許可などの最初の手順は [チュートリアル](tutorial.md) と [アクセシビリティの許可](accessibility.md) を見てください。

## 「アプリケーション」フォルダへ移動する

DMG やダウンロードフォルダなど、「アプリケーション」フォルダの外から TatakiNote を開くと、起動した直後に「TatakiNote を「アプリケーション」フォルダへ移動しますか?」と聞かれます。説明文は「「アプリケーション」フォルダに置くと、アップデートを入れられます。」です。

- 「移動する」: TatakiNote を「アプリケーション」フォルダへ移し、そこにある TatakiNote を開き直します。DMG から開いたときは DMG の中の TatakiNote を残して写し、ダウンロードフォルダなどから開いたときは元の TatakiNote を消して移します。「アプリケーション」フォルダに同じ名前の TatakiNote があるときは、新しいものに置き換わります。
- 動いているほかの TatakiNote(前の版を含む)があるときは、説明文に「動いている TatakiNote は、移動の前に終了します。」が加わります。「移動する」を選ぶと、それらを終了してから移します。終了しなかったときは「動いている TatakiNote を終了できませんでした。」と出て、移さずにその場所のまま使えます。メニューバーの TatakiNote から「終了」を選んでから、もう一度開いてください。
- 「移動しない」: 何も移さず、その場所のまま使えます。次に開いたときも、また聞かれます。
- 「今後は聞かない」にチェックして「移動しない」を選ぶと、以後は聞かれません。「移動する」を選んだときは、このチェックに関係なく移動します。
- 移せなかったときは、「「アプリケーション」フォルダへ移動できませんでした。」と出ます。Finder で TatakiNote を「アプリケーション」フォルダへドラッグしてください。
- 「アプリケーション」フォルダ(ホームフォルダの「Applications」を含む)の中から開いたときは、聞かれません。

## 新しい版を自動で確かめる

- 1日に1回、新しい版があるかを自動で確かめます。TatakiNote を起動したときと、Mac のスリープから戻ったとき、ネットワークにつながり直したときにも、前回の確認から1日以上たっていれば確かめます。
- ネットワークにつながっていない間は確かめず、何も表示しません。確かめられなかったときも、何も表示しません。
- 自動で確かめているときは、窓は出ません。

## 新しい版があるとき

新しい版が見つかると、次の印が付きます。

- メニューバーのアイコンに印が付きます。
- Dock にアイコンを表示しているときは、Dock のアイコンに印が付きます。
- 設定ウィンドウのサイドバーの「情報」に印が付き、「情報」に「新しい版 <版> があります」と「詳しく見る…」が出ます。
- メニューバーのメニューの先頭に「新しい版があります(<版>)」が出ます。

メニューの「新しい版があります(<版>)」か、設定の「情報」の「詳しく見る…」を選ぶと、新しい版の変更点の窓が開きます。窓では次を選べます。

- 「アップデートをインストール」: 新しい版をダウンロードして入れ替え、TatakiNote を開き直します。パネルに書きかけの文章があれば、開き直したあとのパネルに戻ります。アクセシビリティの許可・設定・下書き・履歴は、そのまま残ります。
- 「後で通知」: 今は入れ替えません。次の自動の確認で、また知らせます。
- 「このバージョンをスキップ」: この版は入れ替えません。

変更点の窓を開いたあとや、窓を閉じたあとは、印が消えます。選ばないかぎり、入れ替わりも再起動もしません。

## 自分で確かめる

「アップデートを確認…」を選ぶと、新しい版があるかを今すぐ確かめます。メニューバーのメニューと、設定の「情報」にあります。「アップデートを自動で確認」がオフのときも使えます。

- 新しい版があるときは、変更点の窓が開きます。
- 最新の版のときは、最新である旨の窓が開きます。
- ネットワークにつながっていないときは、確かめられなかった旨の窓が開きます。
- 確かめている間や、変更点の窓が開いている間は、「アップデートを確認…」は選べません。

## 自動の確認をオフにする

設定の「情報」にある「アップデートを自動で確認」をオフにします。初期値はオンです。オフの間は、自動では確かめません。オンに戻すと、その場で確かめるかを判断します。印が付いているときにオフにしても、印は残ります。

設定の見方は [設定ウィンドウ](settings.md#情報の項目) を見てください。メニューの項目は [メニューバーのメニュー](panel.md#メニューバーのメニュー) を見てください。
