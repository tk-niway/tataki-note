# 入力パネル

TatakiNote の入力パネルは、文章を書くための小さなウィンドウです。
パネルを開いても、使っていたアプリは前面のままです。パネルでは `↩`(Return)が改行になるので、日本語の変換や改行を気にせずに書けます。

## パネルを開く

| 操作 | 結果 |
|---|---|
| ホットキー `⌥⇧Space`(Option + Shift + Space。初期値) | パネルが閉じていれば開きます。開いていれば閉じます |
| メニューバーの TatakiNote のアイコン →「パネルを開く」 | パネルを開きます。すでに開いているときは閉じずに、位置はそのままで入力欄の文章の末尾にカーソルを置きます |
| 他のアプリで入力欄を選ぶ(設定の「自動表示」が「全アプリ」か「選んだアプリのみ」のとき) | パネルが自動で開きます。条件は [入力欄を選んだらパネルを自動で出す](auto-show.md) |
| Dock のアイコン、または Finder や Spotlight から TatakiNote を開く | パネルが閉じていれば、挿入先なしで開きます。開いているときは何もしません |
| TatakiNote を起動する | チュートリアルや許可の案内が出ないときは、パネルが挿入先なしで開きます。ログイン時の自動起動では開きません |

- 挿入先なしで開いたパネルでも、他のアプリの入力欄をクリックすると、そこが挿入先になります([挿入先を選び直す](insert-and-send.md#挿入先を選び直す))。
- 終了前の確認の窓が出ている間は、ホットキー・自動表示・アイコンからの起動でパネルは開閉しません。

- パネルを開いても、使っていたアプリは前面のままです。メニューバーのメニューを開いたときも同じです。
- 開いた直後から、クリックせずにそのまま文字を打てます。カーソルは文章の末尾に置かれます。
- 入力欄が空のときは「ここにプロンプトを書く…」と表示されます。
- ホットキーはどのアプリを使っているときでも効きます。変え方は [ホットキーを変える](settings.md#ホットキーを変える)。

## 開閉の動き

パネルは、開くときは横一本の線が上下に広がって現れ、閉じるときは上下に縮んで線になって消えます(どちらも約 0.2 秒)。ホットキー・メニュー・自動表示のどれで開いても、`esc`・ホットキー・閉じるボタン・`⌘H`・確定のどれで閉じても、同じ動きです。

- 広がっている途中から、そのまま文字を打てます。
- 確定(挿入・送信)して挿入できるときは、閉じる動きを待たずに文章を入れます。「挿入先なし」のときは、パネルは閉じません。閉じる動きの間も、使っていたアプリは前面のままです。
- 閉じる動きの途中で開き直すと、閉じる動きをやめて、線から開く動きになります。
- `⌘H` で閉じたときは、パネルが縮んで消えたあとに TatakiNote が隠れます。
- `⌘H` 以外の方法で TatakiNote が隠れたときは、パネルは動きなしですぐに閉じます。
- 動きは、設定の「一般」→「外観」の「アニメーション」で切れます(初期値は「オン」)。「オフ」にすると、開くときも閉じるときも、動きなしですぐに出入りします([アニメーションを切り替える](settings.md#アニメーションを切り替える))。

## パネルで書いて閉じる

| キー | 動き |
|---|---|
| `↩`(Return。テンキーの Enter も同じ) | 改行します(パネルは閉じません) |
| `esc`(Escape) | パネルを閉じます(書いた文章は残ります)。サイドバーの検索欄にいるときは、入力欄に戻ります。サイドバーの一覧にいるときは、パネルを閉じます |
| ホットキー `⌥⇧Space` | パネルを閉じます(書いた文章は残ります) |
| `⌘K` / `⌘S` / `⌘N`(Command + K / S / N) | サイドバーを開いて検索 / 下書きに保存 / 新しい書きかけにする([下書きと履歴](drafts-and-history.md)) |
| `⇧⌘S`(Shift + Command + S) | パネルの文章をテキストファイルに書き出します([ファイルに書き出す](drafts-and-history.md#ファイルに書き出す)) |
| `⌘E`(Command + E) | 今の書きかけを、インサートとノートで切り替えます([書きかけのモード](#書きかけのモード)) |
| `⌘B`(Command + B) | サイドバーを開く・閉じる([下書きと履歴](drafts-and-history.md)) |
| `⌘,`(Command + カンマ) | パネルを開いたまま、[設定ウィンドウ](settings.md)を開きます。設定ウィンドウを閉じると、キー入力はパネルに戻ります |
| `⌘H`(Command + H) | パネルを閉じます |
| `⌘A`(Command + A) | すべて選択します |
| `⌘C` / `⌘X` / `⌘V`(Command + C / X / V) | 選択している範囲のコピー・切り取り・貼り付け。何も選択していないときは行ごとの操作になります([入力欄の編集ショートカット](text-editing.md)) |
| `⌘Z` / `⇧⌘Z`(Command + Z / Shift + Command + Z) | 取り消し / やり直し |

- パネルの下の帯に、キーのヒントと、書いた文字数・行数が出ています。詳しくは [パネルの下の帯](#パネルの下の帯)。
- 日本語入力などで変換中(未確定の文字がある間)の `esc` と `↩` は、入力メソッドの取り消し・確定になり、パネルは閉じません。
- パネルのタイトルバーの左端にある閉じるボタン(×)をクリックしても閉じます。書いた文章は残り、ドラッグで変えた大きさも `esc` と同じく保たれ、使っていたアプリは前面のままです。日本語入力などで変換中(未確定の文字がある間)にクリックしたときは、変換中の `esc` と違ってパネルが閉じます。未確定の文字は今の読みのまま確定して、文章に含まれます。閉じるボタンの右に、サイドバーの開閉ボタンが並びます。
- タイトルバーの右には、新しい書きかけにするアイコン・下書きに保存するアイコン・共有のアイコンと、インサートの書きかけでは文章が入るアプリを示す「挿入先」(ないときは「挿入先なし」)が出ます。ノートの書きかけでは、同じ場所に「ノート」が出ます。詳しくは [下書きと履歴](drafts-and-history.md#パネルのタイトルバー)。
- パネルはタイトルバーだけでなく、背景をドラッグしても動かせます。
- 入力欄はプレーンテキストです。コードを書いても崩れないように、引用符・ダッシュの自動置換とテキスト置換は働きません。
- 入力欄の文字のフォントと大きさ、パネル全体の透明度は、設定の「パネル」で変えられます([パネルの項目](settings.md#パネルの項目))。
- 行の移動・複製や、行・単語の選択などのキー操作は [入力欄の編集ショートカット](text-editing.md) にまとめています。
- 書いた文章をアプリに入れる操作(確定)は [書いた文章を挿入する・送信する](insert-and-send.md) を見てください。

## パネルの下の帯

パネルの下には、帯があります。左側にキーのヒント、右側に書いた量が出ます。キーはキーキャップの形で表示されます。

| 表示 | 位置 | 意味 |
|---|---|---|
| 「esc 閉じる」 | 左 | `esc` でパネルを閉じます(書いた文章は残ります) |
| 「↩ 改行」 | 左 | `↩` で改行します |
| 「⇧⌘↩ 挿入」 | 左 | 確定+挿入キーで、書いた文章を挿入します。キーの表示は、設定で登録したキー(例 `⌘J`)に合わせて変わります(初期値は `⇧⌘↩`) |
| 「⌘↩ 送信」 | 左 | 確定+送信キーで、挿入して送信します。キーの表示は、設定で登録したキーに合わせて変わります(初期値は `⌘↩`) |
| 「57文字」 | 右 | 今書いている文章の文字数 |
| 「4行」 | 右 | 今書いている文章の行数 |

- 「挿入」「送信」はクリックできるボタンです。クリックすると、確定+挿入キー・確定+送信キーを押したときと同じ確定になります(変換中の文字は確定してから挿入します)。マウスを乗せると「挿入(⇧⌘↩)」のように名前とキーが出ます。クリックしても、使っていたアプリは前面のままです。「esc 閉じる」と「↩ 改行」はヒントで、クリックしても何も起きません。
- ノートの書きかけでは、「挿入」「送信」の項目は帯に出ません([書きかけのモード](#書きかけのモード))。
- 設定の「確定+挿入キー」「確定+送信キー」を登録していないと、その項目は帯に出ません。キーを変えると、パネルが開いていても帯の表示が変わります。キーの登録の仕方は [確定のキー](insert-and-send.md#確定のキー)。
- 帯に出す項目は、設定の「パネル」→「帯に出す項目」で選べます(6項目それぞれのオン・オフ。すべて外すと帯ごと消えて、そのぶん入力欄が広がります)。詳しくは [帯に出す項目を選ぶ](settings.md#帯に出す項目を選ぶ)。
- 文字数と行数は、書いている間ずっと、今の文章に合わせて変わります。何も書いていなければ「0文字」「0行」です。
- 文字数は、空白(半角・全角・タブ)を数え、改行は数えません。絵文字や濁点付きの文字などは、見た目の1文字を1と数えます。
- 行数は、改行で区切った行の数です。画面での折り返しは数えません。文章が改行で終わるときは、その後ろの空の行も1行と数えます。
- 日本語入力で変換中の(まだ確定していない)文字も、数に入ります。
- 1,000 以上の数は、3桁ごとに区切って表示します(区切りの記号は Mac の地域の設定に従います)。
- 幅が足りないときは、まず「閉じる」の説明が消えて `esc` だけになり、それでも足りなければ、すべてのキーの説明が消えてキーの表示だけになります。

## 書きかけ

- パネルを閉じても、書いた文章はパネルに残ります。次に開くと、そのまま続きを書けます。
- 保存していない文章(書きかけ)は、別の下書き・履歴を開いたときや `⌘N` で新しい書きかけにしたとき、TatakiNote を終了したときに、挿入していない文章として履歴に残ります([書きかけは履歴に残る](drafts-and-history.md#書きかけは履歴に残る))。残したい文章は、`⌘S` で下書きに保存します([下書きと履歴](drafts-and-history.md))。
- 確定して挿入できると、パネルは空になります。
- 文章が空のまま確定や `⌘S` をすると、パネルは閉じずに横に揺れて、書く文章が無いことを知らせます。開く動きの途中では揺れません。設定の「アニメーション」がオフのときは、揺れずに警告音が鳴ります。
- 挿入できなかったときは、文章がパネルに残る(戻る)ので、そのまま確定し直せます。詳しくは [確定したときの動き](insert-and-send.md#確定したときの動き)。

## 書きかけのモード

書きかけは、「インサート」と「ノート」のどちらかのモードを持ちます。書きかけごとに切り替えられます。

| モード | 動き |
|---|---|
| インサート | 確定+挿入キー・確定+送信キーで、書いた文章を挿入先に入れます。ふだんの使い方です。タイトルバーの右端に「挿入先」が出ます |
| ノート | 挿入も送信もしません。確定+挿入キー・確定+送信キーは改行になります(登録したキーも同じです)。送るつもりのない文章を、確定のキーの押し間違いで挿入・送信してしまうのを防ぎます |

- 切り替えるには、`⌘E`(Command + E)を押します。入力欄・サイドバーの一覧・検索欄のどこにいても使えます。日本語入力で変換中の `⌘E` は、入力メソッドに渡ります。
- ノートの書きかけでは、タイトルバーの右端に「挿入先」の代わりに色の付いた「ノート」が出ます。「ノート」をクリックしても、インサートに戻せます(インサートからノートへは `⌘E` だけです)。
- ノートの書きかけでは、帯に「挿入」「送信」が出ず、「挿入」「送信」のクリックでも確定しません。入力欄を囲む枠線は、設定でオンにしていても出ません。インサートに戻すと、その場で出ます。挿入先は、ノートのあいだも調べ続けます。
- ノートの書きかけで、他のアプリの入力欄をクリックしたときは、挿入先はその入力欄に移りますが、キー入力はパネルに戻らず、クリックしたアプリで打てます。パネルに戻るには、パネルをクリックします(インサートの書きかけでは、パネルに戻ります。[挿入先を選び直す](insert-and-send.md#挿入先を選び直す))。
- ノートの書きかけでも、`⌘S` で下書きに保存でき、サイドバーも使えます。
- 新しい書きかけは、設定の「モード」で選んだモードで始まります(初期値は「インサート」。[新しい書きかけのモードを選ぶ](settings.md#新しい書きかけのモードを選ぶ))。新しい書きかけになるのは、起動したとき・`⌘N` や新規作成のアイコンを押したとき・文章を挿入できたあとです。[チュートリアル](tutorial.md)を開いている間は、設定にかかわらずインサートで始まります。
- 下書きや履歴を開いたとき、パネルを閉じて開き直したとき、挿入できずに文章がパネルに戻ったときは、モードは変わりません。

## パネルが出る場所

- パネルは、画面のメニューバーと Dock を除いた領域の中央に出ます。どこに出すかは、設定の「パネル」の「パネルを出す位置」で選べます(初期値は「入力欄の近く」)。「入力欄の近く」を選ぶと、選ばれている入力欄の近くに出ます([入力欄の近くに出るとき](#入力欄の近くに出るとき))。「マウスの近く」を選ぶと、マウスポインタの近くに出ます。
- パネルが開いたままメニューの「パネルを開く」を選び直したときは、位置も大きさも変えません(開いているときにホットキーを押すと、パネルは閉じます)。
- ドラッグで動かしても、閉じて開き直すと、選んだ画面の中央(「入力欄の近く」のときは入力欄の近く、「マウスの近く」のときはそのときのマウスポインタの近く)に戻ります。パネルの大きさは [パネルの大きさ](#パネルの大きさ) のとおりです。

### パネルを出す位置を選ぶ

メニューバーの TatakiNote のアイコン →「設定」→「パネル」→「パネルを出す位置」の4つのタイル(画面の小さな図が付いています)から選びます。パネルを閉じた状態から新しく開くときに効きます。

| 選択肢 | パネルが出る場所 |
|---|---|
| 「入力欄の近く」(初期値) | 挿入先のアプリで選ばれている入力欄の近く。入力欄の位置が分かるときは、入力欄と最も大きく重なっている画面に出ます([入力欄の近くに出るとき](#入力欄の近くに出るとき))。位置が分からないときは、「挿入先のウィンドウがある画面」と同じ画面の中央 |
| 「挿入先のウィンドウがある画面」 | パネルを開いたときに使っていたアプリ(挿入先)の、いちばん手前のウィンドウが最も大きく重なっている画面。挿入先やそのウィンドウが分からないとき・どの画面とも重ならないときは、マウスのある画面 |
| 「マウスの近く」 | マウスポインタのある画面の、ポインタのすぐ下。パネルの左端がポインタにそろうように出ます。下に収まらないときはポインタのすぐ上に出し、上にも収まらないときはその画面の中央に出します。画面の左右の端からはみ出すときは内側へずらします |
| 「メインの画面」 | システム設定の「ディスプレイ」でメインディスプレイにしている画面 |

- 「挿入先のウィンドウがある画面」と「入力欄の近く」では、ウィンドウや入力欄の位置だけを調べます。ウィンドウの中身は読まないので、画面収録の許可は要りません。

### 入力欄の近くに出るとき

「パネルを出す位置」を「入力欄の近く」にすると、ホットキー・メニュー・自動表示のどれで開いても、挿入先のアプリで選ばれている入力欄の近くにパネルが出ます。

- 入力欄の下に少し空けて、パネルの左端を入力欄の左端にそろえて出ます(入力欄には重なりません)。
- 下に収まらないときは、入力欄の上に出ます(入力欄には重なりません)。
- 上にも収まらないとき(入力欄が大きい・画面の上下の端にある)は、入力欄のある画面の中央に出ます。入力欄に重なることがあります。
- 横は、画面からはみ出さないように内側へずれます。
- 開いたあとに入力欄が動いても、パネルは動きません。閉じて開き直すたびに、そのときの入力欄の近くに出ます。
- 入力欄の位置が分からないとき(入力欄以外が選ばれている・アプリが位置を教えない・アクセシビリティの許可が無い)は、「挿入先のウィンドウがある画面」と同じ画面の中央に出ます。入力欄の位置を調べるには、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。

## パネルの大きさ

パネルは、開くときは既定の大きさで開きます。初期値は 520 × 340 ポイントで、設定の「パネル」→「パネルのサイズ」で変えられます([パネルの既定の大きさを変える](settings.md#パネルの既定の大きさを変える))。画面より大きいときは、収まるように縮んで開きます。

### 大きさを変える

- パネルの端や角をドラッグすると、幅と高さを変えられます。使っていたアプリは前面のままです。
- 小さくできるのは 320 × 160 ポイントまでです。
- タイトルバーをダブルクリックしても、パネルは画面いっぱいには広がりません。
- ドラッグで変えた大きさは、文章を挿入するまで保たれます。文章が入ったまま `esc` や閉じるボタンで閉じて開き直したときも、挿入できずにパネルに残ったときも、同じ大きさで開きます。空のまま確定したときはパネルが閉じないので、大きさもそのままです。
- パネルが空のまま閉じて開き直すと、ドラッグで変えた大きさは捨てられ、既定の大きさで開きます。
- サイドバーを開くとパネルが左へ広がります(画面の左端で入らないときは、パネルが右へずれます)。ここで言う大きさは、サイドバーを除いた文章の部分の大きさです。ドラッグで変えた大きさも、サイドバーの幅を含みません。サイドバーを閉じると元の幅に戻ります([下書きと履歴](drafts-and-history.md#サイドバーで探して呼び出す))。
- 文章を挿入できると、次に開くときは既定の大きさ(初期値は 520 × 340 ポイント)に戻ります。TatakiNote を起動し直したときも既定の大きさに戻ります。
- 保たれている間は、設定の「パネルのサイズ」を変えても、挿入するまではドラッグで変えた大きさで開きます。ドラッグで決めた大きさをずっと使いたいときは、設定の「今のパネルサイズを既定にする」で既定の大きさにします。
- 保たれるのはドラッグで変えた辺だけです。幅だけを変えたときは、高さは既定の高さ(初期値は 340 ポイント)のままです(高さだけを変えたときは、幅が既定のままです)。

### 文章が長いとき

- 行が増えて入力欄に収まらなくなっても、パネルの大きさは変わりません。入力欄の中で上下にスクロールします。
- 末尾で文字を打つと、カーソルの位置が見えるところまで入力欄が自動でスクロールします。
- パネルを開いたときの高さは、文章の量に関わらず、いつも既定の大きさ(ドラッグで変えていれば、その大きさ)です。

## メニューバーのメニュー

メニューバーの TatakiNote のアイコン(紙が 2 枚重なり、手前の紙に丸い点がある形)をクリックすると、次の項目が並びます。Dock のアイコンは、設定の「Dock にアイコンを表示」で出し入れできます(初期値はオン。[Dock のアイコン](settings.md#dock-のアイコン))。

| 項目 | キー | 動き | 詳しく |
|---|---|---|---|
| 「新しい版があります(<版>)」(新しい版があるときだけ、先頭に出ます) | — | 新しい版の変更点の窓を開きます | [アップデートとインストール](updates.md) |
| 「パネルを開く」 | 今のホットキーが表示されます | パネルを開きます | [パネルを開く](#パネルを開く) |
| 「設定」 | `⌘,`(Command + カンマ) | 設定ウィンドウを開きます | [設定ウィンドウ](settings.md) |
| 「アップデートを確認…」 | — | 新しい版があるかを確かめます。自動の確認がオフのときも使えます | [アップデートとインストール](updates.md) |
| 「終了」 | `⌘Q`(Command + Q) | TatakiNote を終了します(書きかけがあれば、履歴に残ります) | — |

- 「パネルを開く」の右のキーは表示のためだけのものです。ホットキーは、メニューを開いていなくても、どのアプリの上でも効きます。
- メニューのキー(`⌘,`・`⌘Q`)は、メニューが開いている間に使えます。メニューの「終了」をクリックしたときは、確認せずにすぐ終了します。`⌘Q` を押した場合は、日本語入力がオンのときも、メニューを開いているときも、設定がオンなら確認の窓が出ます([終了前の確認](settings.md#終了前の確認))。
- 設定で「メニューバーにアイコンを表示」をオフにすると、このメニューは使えなくなります([メニューバーのアイコン](settings.md#メニューバーのアイコン))。
