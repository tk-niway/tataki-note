# 入力パネル

TatakiNote の入力パネルは、文章を書くための小さなウィンドウです。
パネルを開いても、使っていたアプリは前面のままです。パネルでは `↩`(Return)が改行になるので、日本語の変換や改行を気にせずに書けます。

## パネルを開く

| 操作 | 結果 |
|---|---|
| ホットキー `⌥⇧Space`(Option + Shift + Space。既定値) | パネルが閉じていれば開きます。開いていれば閉じます |
| メニューバーの TatakiNote のアイコン →「パネルを開く」 | パネルを開きます。すでに開いているときは閉じずに、位置はそのままで入力欄にカーソルを戻します |
| 他のアプリで入力欄を選ぶ(設定の「自動表示」が「全アプリ」か「選んだアプリのみ」のときだけ) | パネルが自動で開きます。条件は [入力欄を選んだらパネルを自動で出す](auto-show.md) |

- パネルを開いても、使っていたアプリは前面のままです。メニューバーのメニューを開いたときも同じです。
- 開いた直後から、クリックせずにそのまま文字を打てます。カーソルは文章の末尾に置かれます。
- 入力欄が空のときは「ここにプロンプトを書く…」と表示されます。
- ホットキーはどのアプリを使っているときでも効きます。変え方は [ホットキーを変える](settings.md#ホットキーを変える)。

## パネルで書いて閉じる

| キー | 動き |
|---|---|
| `↩`(Return。テンキーの Enter も同じ) | 改行します(パネルは閉じません) |
| `esc`(Escape) | パネルを閉じます(下書きは残ります) |
| ホットキー `⌥⇧Space` | パネルを閉じます(下書きは残ります) |
| `⌘H`(Command + H) | パネルを閉じます |
| `⌘A`(Command + A) | すべて選択します |
| `⌘C` / `⌘X` / `⌘V`(Command + C / X / V) | 選択している範囲のコピー・切り取り・貼り付け。何も選択していないときは行ごとの操作になります([入力欄の編集ショートカット](text-editing.md)) |
| `⌘Z` / `⇧⌘Z`(Command + Z / Shift + Command + Z) | 取り消し / やり直し |

- パネルの下の帯に、キーのヒントと、書いた文字数・行数が出ています。詳しくは [パネルの下の帯](#パネルの下の帯)。
- 日本語入力などで変換中(未確定の文字がある間)の `esc` と `↩` は、入力メソッドの取り消し・確定になり、パネルは閉じません。
- パネルのタイトルバーの左端にある閉じるボタン(×)をクリックしても閉じます。下書きは残り、ドラッグで変えた大きさも `esc` と同じく保たれ、使っていたアプリは前面のままです。日本語入力などで変換中(未確定の文字がある間)にクリックしたときは、変換中の `esc` と違ってパネルが閉じます。未確定の文字は今の読みのまま確定して下書きに含まれます。
- パネルはタイトルバーだけでなく、背景をドラッグしても動かせます。
- 入力欄はプレーンテキストです。コードを書いても崩れないように、引用符・ダッシュの自動置換とテキスト置換は働きません。
- 入力欄の文字のフォントと大きさ、パネル全体の透明度は、設定の「エディタ設定」で変えられます([エディタ設定の項目](settings.md#エディタ設定の項目))。
- 行の移動・複製や、行・単語の選択などのキー操作は [入力欄の編集ショートカット](text-editing.md) にまとめています。
- 書いた文章をアプリに入れる操作(確定)は [書いた文章を挿入する・送信する](insert-and-send.md) を見てください。

## パネルの下の帯

パネルの下には、細い帯があります。左側にキーのヒント、右側に書いた量が出ます。

| 表示 | 位置 | 意味 |
|---|---|---|
| 「esc 閉じる」 | 左 | `esc` でパネルを閉じます(下書きは残ります) |
| 「↩ 改行」 | 左 | `↩` で改行します |
| 「⌘↩ 確定」 | 左 | 確定キーで、書いた文章を挿入します。キーの表示は、設定で登録したキー(例 `⌘K`)に合わせて変わります。既定値は登録なしなので、キーを登録するまで出ません |
| 「⌘↩ 確定+送信」 | 左 | 確定+送信キーで、挿入して送信します。キーの表示は、設定で登録したキーに合わせて変わります(既定値は `⌘↩`) |
| 「57文字」 | 右 | 今書いている文章の文字数 |
| 「4行」 | 右 | 今書いている文章の行数 |

- 設定の「確定キー」「確定+送信キー」を登録していないと、その項目は帯に出ません。キーを変えると、パネルが開いていても帯の表示が変わります。キーの登録の仕方は [確定のキー](insert-and-send.md#確定のキー)。
- 帯に出す項目は、設定の「エディタ設定」→「帯に出す項目」で選べます(6項目それぞれのオン・オフ。すべて外すと帯ごと消えて、そのぶん入力欄が広がります)。詳しくは [帯に出す項目を選ぶ](settings.md#帯に出す項目を選ぶ)。
- 文字数と行数は、書いている間ずっと、今の文章に合わせて変わります。何も書いていなければ「0文字」「0行」です。
- 文字数は、空白(半角・全角・タブ)を数え、改行は数えません。絵文字や濁点付きの文字などは、見た目の1文字を1と数えます。
- 行数は、改行で区切った行の数です。画面での折り返しは数えません。文章が改行で終わるときは、その後ろの空の行も1行と数えます。
- 日本語入力で変換中の(まだ確定していない)文字も、数に入ります。
- 1,000 以上の数は、3桁ごとに区切って表示します(区切りの記号は Mac の地域の設定に従います)。
- 幅が足りないときは、まず「閉じる」の説明が消えて `esc` だけになり、それでも足りなければ、すべてのキーの説明が消えてキーの表示だけになります。

## 下書き

- パネルを閉じても、書いた文章は下書きとして残ります。次に開くと、そのまま続きを書けます。
- 下書きは TatakiNote が動いている間だけ残ります。ファイルには保存されないので、TatakiNote を終了すると消えます。
- 確定して挿入できると、下書きは空になります。
- 挿入できなかったときは、文章が下書きに戻ります。詳しくは [確定したときの動き](insert-and-send.md#確定したときの動き)。

## パネルが出る場所

- パネルは、画面のメニューバーと Dock を除いた領域の中央に出ます。どの画面に出すかは、設定の「パネルを出す位置」で選べます(既定値は「入力欄の近く」)。「入力欄の近く」を選ぶと、選ばれている入力欄の近くに出ます([入力欄の近くに出るとき](#入力欄の近くに出るとき))。
- パネルが開いたままメニューの「パネルを開く」を選び直したときは、位置も大きさも変えません(開いているときにホットキーを押すと、パネルは閉じます)。
- ドラッグで動かしても、閉じて開き直すと、選んだ画面の中央(「入力欄の近く」のときは入力欄の近く)に戻ります。パネルの大きさは [パネルの大きさ](#パネルの大きさ) のとおりです。

### パネルを出す位置を選ぶ

メニューバーの TatakiNote のアイコン →「設定」→「一般」→「パネルを出す位置」のラジオボタンから選びます。パネルを閉じた状態から新しく開くときに効きます。

| 選択肢 | パネルが出る画面 |
|---|---|
| 「入力欄の近く」(既定値) | 挿入先のアプリで選ばれている入力欄の近く。入力欄の位置が分かるときは、入力欄と最も大きく重なっている画面に出ます([入力欄の近くに出るとき](#入力欄の近くに出るとき))。位置が分からないときは、「挿入先のウィンドウがある画面」と同じ画面の中央 |
| 「挿入先のウィンドウがある画面」 | パネルを開いたときに使っていたアプリ(挿入先)の、いちばん手前のウィンドウが最も大きく重なっている画面。挿入先やそのウィンドウが分からないとき・どの画面とも重ならないときは、マウスのある画面 |
| 「マウスのある画面」 | マウスポインタのある画面 |
| 「メインの画面」 | システム設定の「ディスプレイ」でメインディスプレイにしている画面 |

- 設定画面の説明文は「パネルを新しく開くときに出す位置です。「入力欄の近く」は、挿入先のアプリで選ばれている入力欄の近くに出します。入力欄の位置が分からないときは、挿入先のウィンドウがある画面の中央に出します。ほかの3つは、その画面の中央に出します(挿入先のウィンドウが分からないときは、マウスのある画面)。「メインの画面」は、システム設定の「ディスプレイ」でメインディスプレイにしている画面です。」です。
- 「挿入先のウィンドウがある画面」と「入力欄の近く」では、ウィンドウや入力欄の位置だけを調べます。ウィンドウの中身は読まないので、画面収録の許可は要りません。

### 入力欄の近くに出るとき

「パネルを出す位置」を「入力欄の近く」にすると、ホットキー・メニュー・自動表示のどれで開いても、挿入先のアプリで選ばれている入力欄の近くにパネルが出ます。

- 入力欄の下に少し空けて、パネルの左端を入力欄の左端にそろえて出ます(入力欄には重なりません)。
- 下に収まらないときは、入力欄の上に出ます(入力欄には重なりません)。
- 上にも収まらないとき(入力欄が大きい・画面の上下の端にある)は、入力欄のある画面の中央に出ます。入力欄に重なることがあります。
- 横は、画面からはみ出さないように内側へずれます。
- 開いたあとに入力欄が動いても、パネルは動きません。閉じて開き直すたびに、そのときの入力欄の近くに出ます。
- 入力欄の位置が分からないとき(入力欄以外が選ばれている・アプリが位置を教えない・アクセシビリティの許可が無い)は、「挿入先のウィンドウがある画面」と同じ画面の中央に出ます。入力欄の位置を調べるには、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。

## パネルの大きさ

パネルは、開くときは既定の大きさで開きます。既定値は 520 × 340 ポイントで、設定の「エディタ設定」→「パネルの既定の大きさ」で変えられます([パネルの既定の大きさを変える](settings.md#パネルの既定の大きさを変える))。画面より大きいときは、収まるように縮んで開きます。

### 大きさを変える

- パネルの端や角をドラッグすると、幅と高さを変えられます。使っていたアプリは前面のままです。
- 小さくできるのは 320 × 160 ポイントまでです。
- タイトルバーをダブルクリックしても、パネルは画面いっぱいには広がりません。
- ドラッグで変えた大きさは、文章を挿入するまで保たれます。`esc` や閉じるボタンで閉じて開き直したときも、挿入できずに下書きに残ったときも、空のまま確定したときも、同じ大きさで開きます。
- 文章を挿入できると、次に開くときは既定の大きさ(初期値は 520 × 340 ポイント)に戻ります。TatakiNote を起動し直したときも既定の大きさに戻ります。
- 保たれている間は、設定の「パネルの既定の大きさ」を変えても、挿入するまではドラッグで変えた大きさで開きます。ドラッグで決めた大きさをずっと使いたいときは、設定の「今のパネルの大きさを既定にする」で既定の大きさにします。
- 保たれるのはドラッグで変えた辺だけです。幅だけを変えたときは、高さは既定の高さ(初期値は 340 ポイント)のままです(高さだけを変えたときは、幅が既定のままです)。

### 文章が長いとき

- 行が増えて入力欄に収まらなくなっても、パネルの大きさは変わりません。入力欄の中で上下にスクロールします。
- 末尾で文字を打つと、カーソルの位置が見えるところまで入力欄が自動でスクロールします。
- パネルを開いたときの高さは、下書きの文章の量に関わらず、いつも既定の大きさ(ドラッグで変えていれば、その大きさ)です。

## メニューバーのメニュー

メニューバーの TatakiNote のアイコン(紙が 2 枚重なり、手前の紙に丸い点がある形)をクリックすると、次の項目が並びます。TatakiNote は Dock にアイコンを出さず、メニューバーにだけ常駐します。起動してもウィンドウは開きません。

| 項目 | キー | 動き | 詳しく |
|---|---|---|---|
| 「パネルを開く」 | 今のホットキーが表示されます | パネルを開きます | [パネルを開く](#パネルを開く) |
| 「設定」 | `⌘,`(Command + カンマ) | 設定ウィンドウを開きます | [設定ウィンドウ](settings.md) |
| 「終了」 | `⌘Q`(Command + Q) | TatakiNote を終了します(下書きは消えます) | — |

- 「パネルを開く」の右のキーは表示のためだけのものです。ホットキーは、メニューを開いていなくても、どのアプリの上でも効きます。
- メニューのキー(`⌘,`・`⌘Q`)は、メニューが開いている間に使えます。
- 設定で「メニューバーのアイコンを隠す」をオンにすると、このメニューは使えなくなります([メニューバーのアイコンを隠す](settings.md#メニューバーのアイコンを隠す))。
