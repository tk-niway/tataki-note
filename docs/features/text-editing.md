# 入力欄の編集ショートカット

パネルの入力欄では、VSCode で使い慣れたキー操作で、行の入れ替え・複製、行ごとのコピー・切り取り・貼り付け、行や単語の選択ができます。
段落や箇条書きの入れ替え、似た行の複製、行単位の切り貼りを、マウスで選び直さずに行えます。動きは VSCode の既定の動きに合わせています。

ここに書いたキーは、パネルの入力欄にカーソルがあるときに使えます(パネルの開き方は [入力パネル](panel.md#パネルを開く))。キーを変えたり、オン・オフを切り替えたりする設定はありません。同じキーの一覧は、設定の「キー」→「ショートカットキー」でも見られます([ショートカットキーの一覧](settings.md#ショートカットキーの一覧))。

## キーの一覧

| キー | 操作 |
|---|---|
| `⌥↑` / `⌥↓`(Option + ↑ / ↓) | カーソルのある行(複数行を選んでいるときは、選択のかかったすべての行)を、1つ上 / 下の行と入れ替えます。カーソル・選択は、移動した行の同じ位置に残ります |
| `⇧⌥↑` / `⇧⌥↓`(Shift + Option + ↑ / ↓) | 行(選択のかかった行)を、その下に複製します。`⇧⌥↑` はカーソル・選択が上側(元の行)に残り、`⇧⌥↓` は下側の複製に移ります |
| `⌘C`(Command + C。何も選択していないとき) | カーソルのある行を、改行ごとクリップボードに入れます。文章とカーソルは変わりません |
| `⌘X`(Command + X。何も選択していないとき) | カーソルのある行を、改行ごと切り取ってクリップボードに入れます |
| `⌘V`(Command + V。行ごとコピー・切り取りした後で、何も選択していないとき) | カーソルのある行の上に、1行として貼り付けます。カーソルは元の行の同じ位置に残ります |
| `⌘L`(Command + L) | カーソルのある行を改行まで選びます。続けて押すと、下の行を1行ずつ選択に加えます。行の途中を選んでいるときは、選択のかかった行全体に広げます |
| `⌘D`(Command + D) | カーソルのある単語を選びます(ダブルクリックと同じ範囲。日本語は語の切れ目)。カーソルが単語のすぐ後ろにあるときは、その単語を選びます |

## 細かい動き

### 行の入れ替えと複製

- **端の行**: いちばん上の行での `⌥↑` と、改行で終わらない最後の行での `⌥↓` は、何もしません(ビープ音も鳴りません)。
- **改行で終わる文章**: 文章が改行で終わるときは、その後ろの空の行も1行として扱います。たとえば1行目が a で、その後ろに空の行があるとき、a の行で `⌥↓` を押すと、1行目が空の行、2行目が a になります。
- **改行で終わらない最後の行**: 1行目が a、2行目が b(最後の行で、改行で終わらない)のとき、b の行で `⌥↑` を押すと、1行目が b、2行目が a になります。行の間の改行はそのまま保たれます。
- **改行まで選んだ行を最後の行の下へ**: 1行目が a、2行目が b(最後の行)のとき、a を改行まで選んで `⌥↓` を押すと、1行目が b、2行目が a になり、選択は a の文字だけ(改行を除く)になります。
- **選択の境目**: 空でない選択が行の先頭ちょうどで終わっているときは、その行は入れ替え・複製の対象に含めません。

### 行ごとのコピーと切り取りと貼り付け

- 改行で終わらない最後の行と、空の文章は、改行を足してクリップボードに入れます。
- 最後の行を切り取るときは、前の行の改行から消します(空の行を残しません)。1行しか無いときは、中身だけが消えます。
- 空の文章で `⌘X` を押すと、改行1つをクリップボードに入れるだけで、文章は変わりません。
- **行ごとの貼り付けになるとき**: 何も選択しておらず、クリップボードの中身が行ごとコピー・切り取りしたものであるときだけです。何かを選択しているとき、または行ごとコピー・切り取りした後に別の内容をコピーしたとき(選択範囲のコピーを含む)は、ふつうの貼り付け(カーソルの位置・選択範囲に貼る)になります。
- **選択しているときの `⌘C` / `⌘X`**: 選択した範囲だけをコピー / 切り取りします。

### 行と単語の選択

- 最後の行まで選んでいるときの `⌘L` は、何もしません。
- 何かを選択しているとき・空白や記号の上・空の文章での `⌘D` は、何もしません。
- 何もしないときも、ビープ音は鳴りません。

### 取り消しと下書き

- 行の入れ替え・複製・行ごとの切り取り・行ごとの貼り付けは、`⌘Z`(Command + Z)で1回ずつ操作の前に戻せます。`⇧⌘Z`(Shift + Command + Z)でやり直せます。
- これらの操作で変わった文章は下書きにも入り、パネルを閉じて開き直しても残ります([下書き](panel.md#下書き))。

## 知っておくこと

- **変換中**: 日本語入力などで未確定の文字がある間は、これらの操作をせず、入力メソッドに任せます。
- **macOS の標準の動きが使えない**: `⌥↑` などの macOS の標準の動き(段落の先頭・末尾への移動、段落単位の選択)は、パネルでは使えません。
- **1行の数え方**: 画面上の折り返しではなく、改行までを1行として数えます。
- **クリップボードが書き換わる**: 何も選択せずに `⌘C` / `⌘X` を押すと、カーソルのある行でクリップボードが書き換わります(VSCode と同じ動き)。誤って押すと、コピーしていた内容が消えます。
