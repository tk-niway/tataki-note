# チュートリアル

「TatakiNote の使い方」のウィンドウで、パネルを開いて書き、送るまでの基本の流れを、AI チャット風の練習用のチャットで1段階ずつ試せます。

## 開き方

- **初めて起動したとき**: 自動で開きます。アクセシビリティの許可が無いときは、先に許可の案内が開き、許可すると案内の「次へ」からチュートリアルに進みます([初めて起動したとき](accessibility.md#初めて起動したとき))。自動で開くのは1回だけです。
- **あとから**: 設定の「アプリ情報」にある「チュートリアル」の「チュートリアルを開く」ボタンで、いつでも開けます([アプリ情報の項目](settings.md#アプリ情報の項目))。開くたびに手順1から始まります。

## 手順

ウィンドウには4つの手順が並び、今の手順だけ説明が出ます。手順を終えると、印が緑のチェックに変わって次に進みます。

1. **パネルを開く** — 下の練習用のチャットの入力欄をクリックしてから、ホットキー(初期値は `⌥⇧Space`)を押します。ホットキーを設定していないときは、設定の「一般」で設定するか、メニューバーの「パネルを開く」で開きます([ホットキーを変える](settings.md#ホットキーを変える))。
2. **Enter で改行しながら書く** — パネルでは、変換の確定にも改行にも Enter を使えます。Enter で送信されることはありません。2行以上の文章を書くと次に進みます。
3. **送る** — 確定+送信キー(初期値は `⌘↩`)を押すと、書いた文章が練習用のチャットに入り、そのまま送信されます。確定+送信キーを登録していないときは、確定+挿入キー(初期値は `⇧⌘↩`)で文章をチャットの入力欄に入れ、内容を確かめてから `↩` で送信します。確定+挿入キーも確定+送信キーも登録されていないときは、設定の「一般」で登録します([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。
4. **次の一歩** — 基本の流れは終わりです。下書き([下書き](panel.md#下書き))とホットキーの変更の紹介が出ます。ここで「完了」を押すとウィンドウが閉じます。

## 練習用のチャット

ウィンドウの下には、AI チャットの画面に似た練習用のチャットがあります。

- 最初に、書きかけのまま送られてしまった例の吹き出しが出ています。変換の確定や改行のつもりで Enter を押して送られてしまう、よくある失敗の例です。
- 入力欄では `↩` で送信、`⇧↩` で改行になります(チャットの右上にも出ています)。変換中の `↩` は、変換を確定してそのまま送信します。
- 送ると、自分の吹き出しのあとに「練習用の自動の返事」が付きます。AI の返事ではなく、送り方に合わせた決まった文です。パネルを使って送ったときは、その送り方の説明が返ります。入力欄に直接書いて `↩` で送ったときは、パネルで書くよう促す文が返ります。この場合、手順 3 は終わりません。

## 知っておくこと

- チュートリアルの間、パネルの挿入先は練習用のチャットの入力欄です。文章を入れるには、他のアプリへの挿入と同じく、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。
- パネルの挿入先が別のアプリになったときは、「パネルの挿入先が別のアプリになっています。」の注意が出ます。このまま確定すると、練習の文章がそのアプリに入り、確定+送信キーでは送信もされます。`esc` でパネルを閉じ、練習用のチャットの入力欄をクリックしてから開き直してください。

## スキップする

手順の途中では右下に「スキップ」が出ます。押すと「チュートリアルをスキップしました。」と、設定の「アプリ情報」からいつでも開けることが出ます。「閉じる」で閉じます。
