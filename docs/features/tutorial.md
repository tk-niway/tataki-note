# チュートリアル

「TatakiNote の使い方」のウィンドウで、パネルを開いて書き、送るまでの基本の流れを、AI チャット風の練習用のチャットで1段階ずつ試せます。

## 開き方

- **初めて起動したとき**: 自動で開きます。アクセシビリティの許可が無いときは、先に許可の案内が開き、許可すると案内の「次へ」からチュートリアルに進みます([初めて起動したとき](accessibility.md#初めて起動したとき))。自動で開くのは1回だけです。
- **あとから**: 設定の「アプリ情報」にある「チュートリアル」の「チュートリアルを開く」ボタンで、いつでも開けます([アプリ情報の項目](settings.md#アプリ情報の項目))。開くたびに手順1から始まります。

## 手順

インサートモードでは、ウィンドウに4つの手順が並び、今の手順だけ説明が出ます。手順を終えると、印が緑のチェックに変わって次に進みます。ノートモードの手順は [ノートモードのとき](#ノートモードのとき) を見てください。

1. **パネルを開く** — 下の練習用のチャットの入力欄をクリックしてから、ホットキー(初期値は `⌥⇧Space`)を押します。ホットキーを設定していないときは、設定の「キー」で設定するか、メニューバーの TatakiNote のアイコンの「パネルを開く」で開きます([ホットキーを変える](settings.md#ホットキーを変える))。
2. **Enter で改行しながら書く** — パネルでは、変換の確定にも改行にも Enter を使えます。Enter で送信されることはありません。2行以上の文章を書くと次に進みます。
3. **送る** — 確定+送信キー(初期値は `⌘↩`)を押すと、書いた文章が練習用のチャットに入り、そのまま送信されます。確定+送信キーを登録していないときは、確定+挿入キー(初期値は `⇧⌘↩`)で文章をチャットの入力欄に入れ、内容を確かめてから `↩` で送信します。確定+挿入キーも確定+送信キーも登録されていないときは、設定の「キー」で登録します([確定+挿入キーと確定+送信キーを登録する](settings.md#確定挿入キーと確定送信キーを登録する))。
4. **次の一歩** — 基本の流れは終わりです。ホットキーの変更、書きかけ([書きかけ](panel.md#書きかけ))、設定の開き方の3つの紹介が出ます。設定の開き方は、メニューバーの TatakiNote のアイコンをクリックして「設定」を選ぶと設定ウィンドウが開くこと、パネルを開いているときは `⌘,` でも開けることです([設定ウィンドウを開く](settings.md#設定ウィンドウを開く))。ここで「完了」を押すとウィンドウが閉じます。

## ノートモードのとき

設定でノートモードにしているときは([モードを切り替える](settings.md#モードを切り替える))、練習用のチャットは出ず、次の3つの手順が並びます。窓の冒頭には「パネルは、どのアプリを使っているときでもホットキーで開ける、書くための場所です。書いた文章は下書きに保存して、あとで続きから書けます。パネルを開いて保存するまでを試してみましょう。」と出ます。

1. **パネルを開く** — ホットキー(初期値は `⌥⇧Space`)を押します。どのアプリを使っているときでも開けます。ホットキーを設定していないときは、手順の説明のとおり、設定の「キー」で設定するか、メニューバーの「パネルを開く」で開きます。パネルが開くと次に進みます。
2. **書いて保存する** — パネルに文章を書いて、`⌘S` を押すか、タイトルバーの「下書きに保存」のアイコンを押します。保存した下書きは、`⌘B` で開くサイドバーからいつでも呼び出せます。下書きに保存されると次に進みます([下書きに保存する](drafts-and-history.md#下書きに保存する))。
3. **次の一歩** — インサートモードと同じ3つの紹介が出ます。「完了」を押すとウィンドウが閉じます。

- 別のアプリが挿入先になっているという注意は出ません。
- チュートリアルを開いたまま設定でモードを切り替えると、切り替えたモードの手順1から始め直します。

## 練習用のチャット

インサートモードのとき、ウィンドウの下には、AI チャットの画面に似た練習用のチャットがあります。

- 最初に、書きかけのまま送られてしまった例の吹き出しが出ています。変換の確定や改行のつもりで Enter を押して送られてしまう、よくある失敗の例です。
- 入力欄では `↩` で送信、`⇧↩` で改行になります(チャットの右上にも出ています)。変換中の `↩` は、変換を確定してそのまま送信します。
- 送ると、自分の吹き出しのあとに「練習用の自動の返事」が付きます。AI の返事ではなく、送り方に合わせた決まった文です。パネルを使って送ったときは、その送り方の説明が返ります。入力欄に直接書いて `↩` で送ったときは、パネルで書くよう促す文が返ります。この場合、手順 3 は終わりません。

## 知っておくこと

- 以下の2つは、インサートモードの場合です。
- チュートリアルの間、パネルの挿入先は練習用のチャットの入力欄です。文章を入れるには、他のアプリへの挿入と同じく、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。
- パネルの挿入先が別のアプリになったときは、「パネルの挿入先が別のアプリになっています。」の注意が出ます。このまま確定すると、練習の文章がそのアプリに入り、確定+送信キーでは送信もされます。`esc` でパネルを閉じ、練習用のチャットの入力欄をクリックしてから開き直してください。

## スキップする

手順の途中では右下に「スキップ」が出ます。押すと「チュートリアルをスキップしました。」と、メニューバーの TatakiNote のアイコン →「設定」→「アプリ情報」からいつでも開けることが出ます。「閉じる」で閉じます。

## 案内の文の中のアイコン

手順1(ホットキーを設定していないとき)・手順4の設定の開き方・スキップの案内では、「メニューバーの TatakiNote のアイコン」の文の中に、メニューバーに出ているのと同じアイコンの画像が文字と同じ行に並びます。メニューバーのどれを探せばよいかの目印です。「メニューバーのアイコンを隠す」をオンにしていても、案内の文は変わりません。
