# チュートリアル

「TatakiNote の使い方」のウィンドウで、パネルを開いて書き、入力欄に入れるまでの基本の流れを、練習用の入力欄で1段階ずつ試せます。

## 開き方

- **初めて起動したとき**: 自動で開きます。アクセシビリティの許可が無いときは、先に許可の案内が開き、許可すると案内の「次へ」からチュートリアルに進みます([初めて起動したとき](accessibility.md#初めて起動したとき))。自動で開くのは1回だけです。
- **あとから**: 設定の「アプリ情報」にある「チュートリアル」の「チュートリアルを開く」ボタンで、いつでも開けます([アプリ情報の項目](settings.md#アプリ情報の項目))。開くたびに手順1から始まります。

## 手順

ウィンドウには4つの手順が並び、今の手順だけ説明が出ます。手順を終えると、印が緑のチェックに変わって次に進みます。

1. **パネルを開く** — 下の「練習用の入力欄」をクリックしてから、ホットキー(既定値は `⌥⇧Space`)を押します。ホットキーを設定していないときは、設定の「一般」で設定するか、メニューバーの「パネルを開く」で開きます([ホットキーを変える](settings.md#ホットキーを変える))。
2. **Enter で改行しながら書く** — パネルでは Enter が改行になり、途中で送信されません。2行以上の文章を書くと次に進みます。
3. **確定して入力欄に入れる** — 確定キーを押すと、練習用の入力欄に文章が入ります。確定キーを設定していないときは、設定の「一般」で設定します([確定キーと確定送信キーを登録する](settings.md#確定キーと確定送信キーを登録する))。
4. **次の一歩** — 基本の流れは終わりです。自動表示([入力欄を選んだらパネルを自動で出す](auto-show.md))、確定+送信([挿入して送信する](insert-and-send.md#挿入して送信する))、ホットキーの変更の紹介が出ます。ここで「完了」を押すとウィンドウが閉じます。

- チュートリアルの間、パネルの挿入先は練習用の入力欄です。文章を入れるには、他のアプリへの挿入と同じく、アクセシビリティの許可が要ります([アクセシビリティの許可](accessibility.md))。
- パネルの挿入先が別のアプリになったときは、「パネルの挿入先が別のアプリになっています。」の注意が出ます。確定せずにパネルを閉じ、練習用の入力欄をクリックしてから開き直してください。

## スキップする

手順の途中では右下に「スキップ」が出ます。押すと「チュートリアルをスキップしました。」と、設定の「アプリ情報」からいつでも開けることが出ます。「閉じる」で閉じます。
