# TatakiNote の使い方

TatakiNote は、AI チャットなどの入力欄で、Enter による誤送信を防ぐための、メニューバーに常駐する macOS アプリです。
ホットキーで開く入力パネルに文章を書き、確定+送信キー(初期値は `⌘↩`)を押すと、パネルを開いたときに使っていたアプリの入力欄に文章が入って送信されます。
パネルでは Enter が改行なので、日本語の変換や改行で書きかけの文章を誤って送信してしまうことがありません。
パネルを開いても、使っていたアプリは前面のままです。

## はじめて使う

- [チュートリアル](features/tutorial.md) — AI チャット風の練習用のチャットで、パネルを開いて書いて送るまでを試します。初めて起動したときに開き、設定の「情報」からいつでも開けます。
- [書きかけのモード](features/panel.md#書きかけのモード) — 書きかけごとに、文章を元のアプリに挿入できる「インサート」と、挿入・送信せず確定のキーが改行になる「ノート」を、`⌘E` で切り替えます。
- [新しい書きかけのモードを選ぶ](features/settings.md#新しい書きかけのモードを選ぶ) — 新しい書きかけを、インサートとノートのどちらで始めるかを、設定の「モード」で選びます。

## 文章を書く

- [パネルを開く](features/panel.md#パネルを開く) — ホットキー(初期値は `⌥⇧Space`。Option + Shift + Space)かメニューから、入力パネルを開きます。
- [開閉の動き](features/panel.md#開閉の動き) — パネルは線から上下に広がって開き、縮んで消えて閉じます。設定の「アニメーション」でオフにできます。
- [パネルで書いて閉じる](features/panel.md#パネルで書いて閉じる) — パネルでのキー操作と、パネルの閉じ方。
- [パネルの大きさ](features/panel.md#パネルの大きさ) — 端のドラッグで大きさを変えられます。文章が入力欄に収まらないときは、パネルの大きさは変わらず入力欄の中でスクロールします。変えた大きさは、文章が入っている間、挿入するまで保たれます(空のパネルは既定の大きさで開きます)。
- [パネルの下の帯](features/panel.md#パネルの下の帯) — 帯に出るキーのヒント(閉じる・改行・確定+挿入・確定+送信)と、書いた文字数・行数。「挿入」「送信」はクリックでも確定できます(ノートの書きかけでは出ません)。
- [書きかけの文章を残す](features/panel.md#書きかけ) — 閉じても書いた文章はパネルに残り、別の文章を開いたときや終了したときは履歴に残ります。
- [下書きと履歴](features/drafts-and-history.md) — `⌘S` で文章を下書きとして保存し、挿入した文章や書きかけの履歴と一緒に、サイドバー(`⌘B` で開閉、`⌘K` で検索。一覧は `↑` `↓` で行き来して中身をすぐ確かめられます)から呼び戻します。タイトルバーには、新規作成・保存のアイコンと、文章が入るアプリ(挿入先。ないときは「挿入先なし」。ノートの書きかけでは「ノート」)が出ます。
- [行の入れ替え・複製などの編集ショートカット](features/text-editing.md) — VSCode のような行の移動・複製、行ごとのコピー・切り取り・貼り付け、行や単語の選択。

## 書いた文章をアプリに入れる

- [挿入する](features/insert-and-send.md#挿入する) — 確定+挿入キーで、書いた文章を元のアプリの入力欄に入れます。
- [確定のキー](features/insert-and-send.md#確定のキー) — 確定+挿入キーと確定+送信キーの登録の仕方と、設定ごとのキーの動き。
- [挿入して送信まで行う](features/insert-and-send.md#挿入して送信する) — 確定+送信キーで、挿入したあと Enter を送って送信します。
- [挿入できなかったとき](features/insert-and-send.md#確定したときの動き) — 挿入できなかったときの動きと、書いた文章がどうなるか。
- [どの入力欄に入るか](features/insert-and-send.md#挿入先の決まり方) — 挿入先の入力欄の決まり方。開いたときの入力欄か、クリックで選んだ入力欄に決まり、開いている間はその位置を見続けます。
- [挿入先を見分ける](features/insert-and-send.md#挿入先を見分ける) — タイトルバーのアイコン・「挿入先なし」と、入力欄を囲む枠線(設定でオフにできます)。ノートの書きかけでは出ません。
- [挿入先を選び直す](features/insert-and-send.md#挿入先を選び直す) — パネルを開いたまま別の入力欄をクリックすると、そこが新しい挿入先になります(ノートの書きかけでは、キー入力はクリックしたアプリに届きます)。
- [クリップボードはどうなるか](features/insert-and-send.md#クリップボードの扱い) — 挿入の後、コピーしていた内容は元に戻ります。

## パネルを自動で出す

- [入力欄を選んだらパネルを出す](features/auto-show.md) — 自動表示の使い方と、自動で出るとき・出ないとき。
- [対象のアプリを選ぶ](features/auto-show.md#対象のアプリを選ぶ) — 「選んだアプリのみ」で使うアプリの足し方・外し方。

## 設定を変える

- [設定ウィンドウ](features/settings.md) — 設定ウィンドウの開き方と、「一般」「ホットキーとキー操作」「パネル」「情報」の項目の一覧。
- [ホットキーを変える](features/settings.md#ホットキーを変える) — パネルを開く・閉じるキーを変えます。
- [確定+挿入キーと確定+送信キーを登録する](features/settings.md#確定挿入キーと確定送信キーを登録する) — 記録ボックスで好きなキーを登録し、受け付けないときは理由を確かめます。
- [パネルを出す位置を選ぶ](features/panel.md#パネルを出す位置を選ぶ) — 入力欄の近く・挿入先のウィンドウがある画面・マウスの近く・メインの画面から選びます。
- [入力欄の近くに出す](features/panel.md#入力欄の近くに出るとき) — 「入力欄の近く」を選ぶと、選ばれている入力欄の下(入らなければ上)にパネルが出ます。
- [フォントと文字サイズを変える](features/settings.md#フォントと文字サイズを変える) — パネルの入力欄の文字のフォントと大きさを選びます。
- [透明度を変える](features/settings.md#透明度を変える) — パネル全体の透け具合を 40〜100% で選びます。
- [パネルの既定の大きさを変える](features/settings.md#パネルの既定の大きさを変える) — パネルを開いたときの大きさを、数値かドラッグした大きさで決めます。
- [帯に出す項目を選ぶ](features/settings.md#帯に出す項目を選ぶ) — パネルの下の帯に出すキーのヒントと文字数・行数を選びます。
- [アニメーションを切り替える](features/settings.md#アニメーションを切り替える) — パネルの開閉や保存の演出など、TatakiNote のすべての動きを、システム・オン・オフから選びます。
- [ショートカットキーの一覧](features/settings.md#ショートカットキーの一覧) — 入力欄で使える編集のキーと、検索・保存・新規・サイドバーの開閉・設定のキーを設定ウィンドウで確かめます。
- [履歴をすべて削除する](features/settings.md#履歴をすべて削除する) — 履歴を、まとめて消します。
- [履歴に残す件数を変える](features/settings.md#履歴に残す件数を変える) — 履歴の上限を 10〜1000 件で決めます(初期値は 200 件)。
- [情報](features/settings.md#情報の項目) — バージョンと、アクセシビリティの許可の状態を確かめ、チュートリアルを開きます。アプリのアイコンを叩くと弾みます。
- [自動で開く](features/settings.md#自動で開く) — 「ホットキーとキー操作」で、自動表示のオフ・全アプリ・選んだアプリのみを選びます。
- [テーマを選ぶ](features/settings.md#テーマを選ぶ) — 「システム」「ライト」「ダーク」から、設定ウィンドウなどの外観を選びます。
- [ログイン時に起動する](features/settings.md#ログイン時に起動する) — Mac にログインしたときに TatakiNote を自動で起動します。
- [メニューバーのアイコンを隠す](features/settings.md#メニューバーのアイコンを隠す) — アイコンを隠したときの開き方と終わらせ方。

## アクセシビリティの許可

- [アクセシビリティの許可](features/accessibility.md) — 挿入と自動表示に要る許可と、許可の手順。許可が無いときの案内は、起動時と確定したときに開きます。
- [許可の状態を確かめる](features/accessibility.md#許可の状態を確かめる) — 設定の「情報」で、今の許可の状態を見られます。
