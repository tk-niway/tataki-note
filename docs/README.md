# TatakiNote の使い方

TatakiNote は、AI チャットなどの入力欄で、Enter による誤送信を防ぐための、メニューバーに常駐する macOS アプリです。
ホットキーで開く入力パネルに文章を書き、確定+送信キー(既定値は `⌘↩`)を押すと、パネルを開いたときに使っていたアプリの入力欄に文章が入って送信されます。
パネルでは Enter が改行なので、日本語の変換や改行で書きかけの文章を誤って送信してしまうことがありません。
パネルを開いても、使っていたアプリは前面のままです。

## はじめて使う

- [チュートリアル](features/tutorial.md) — AI チャット風の練習用のチャットで、パネルを開いて書いて送るまでを試します。初めて起動したときに開き、設定の「アプリ情報」からいつでも開けます。

## 文章を書く

- [パネルを開く](features/panel.md#パネルを開く) — ホットキー(既定値は `⌥⇧Space`。Option + Shift + Space)かメニューから、入力パネルを開きます。
- [パネルで書いて閉じる](features/panel.md#パネルで書いて閉じる) — パネルでのキー操作と、パネルの閉じ方。
- [パネルの大きさ](features/panel.md#パネルの大きさ) — 端のドラッグで大きさを変えられます。文章が入力欄に収まらないときは、パネルの大きさは変わらず入力欄の中でスクロールします。変えた大きさは、文章を挿入するまで保たれます。
- [パネルの下の帯](features/panel.md#パネルの下の帯) — 帯に出るキーのヒント(閉じる・改行・確定・確定+送信)と、書いた文字数・行数。
- [書きかけの文章を残す](features/panel.md#下書き) — 閉じても書いた文章は下書きとして残ります。
- [行の入れ替え・複製などの編集ショートカット](features/text-editing.md) — VSCode のような行の移動・複製、行ごとのコピー・切り取り・貼り付け、行や単語の選択。

## 書いた文章をアプリに入れる

- [挿入する](features/insert-and-send.md#挿入する) — 確定キーで、書いた文章を元のアプリの入力欄に入れます。
- [確定のキー](features/insert-and-send.md#確定のキー) — 確定キーと確定+送信キーの登録の仕方と、設定ごとのキーの動き。
- [挿入して送信まで行う](features/insert-and-send.md#挿入して送信する) — 確定+送信キーで、挿入したあと Enter を送って送信します。
- [挿入できなかったとき](features/insert-and-send.md#確定したときの動き) — 挿入できなかったときの動きと、書いた文章がどうなるか。
- [どのアプリに入るか](features/insert-and-send.md#挿入先の決まり方) — 挿入先のアプリの決まり方。
- [挿入できなかったことの知らせ](features/insert-and-send.md#通知とビープ音) — 通知の文面と、通知が出せないときのビープ音。
- [クリップボードはどうなるか](features/insert-and-send.md#クリップボードの扱い) — 挿入の後、コピーしていた内容は元に戻ります。

## パネルを自動で出す

- [入力欄を選んだらパネルを出す](features/auto-show.md) — 自動表示の使い方と、自動で出るとき・出ないとき。
- [対象のアプリを選ぶ](features/auto-show.md#対象のアプリを選ぶ) — 「選んだアプリのみ」で使うアプリの足し方・外し方。

## 設定を変える

- [設定ウィンドウ](features/settings.md) — 設定ウィンドウの開き方と、「一般」「キー」「パネル」「アプリ情報」の項目の一覧。
- [ホットキーを変える](features/settings.md#ホットキーを変える) — パネルを開く・閉じるキーを変えます。
- [確定キーと確定送信キーを登録する](features/settings.md#確定キーと確定送信キーを登録する) — 記録ボックスで好きなキーを登録し、受け付けないときは理由を確かめます。
- [パネルを出す位置を選ぶ](features/panel.md#パネルを出す位置を選ぶ) — 入力欄の近く・挿入先のウィンドウがある画面・マウスのある画面・メインの画面から選びます。
- [入力欄の近くに出す](features/panel.md#入力欄の近くに出るとき) — 「入力欄の近く」を選ぶと、選ばれている入力欄の下(入らなければ上)にパネルが出ます。
- [フォントと文字サイズを変える](features/settings.md#フォントと文字サイズを変える) — パネルの入力欄の文字のフォントと大きさを選びます。
- [透明度を変える](features/settings.md#透明度を変える) — パネル全体の透け具合を 40〜100% で選びます。
- [パネルの既定の大きさを変える](features/settings.md#パネルの既定の大きさを変える) — パネルを開いたときの大きさを、数値かドラッグした大きさで決めます。
- [帯に出す項目を選ぶ](features/settings.md#帯に出す項目を選ぶ) — パネルの下の帯に出すキーのヒントと文字数・行数を選びます。
- [ショートカットキーの一覧](features/settings.md#ショートカットキーの一覧) — 入力欄で使える編集のキーを設定ウィンドウで確かめます。
- [アプリ情報](features/settings.md#アプリ情報の項目) — バージョンと、アクセシビリティの許可の状態を確かめ、チュートリアルを開きます。
- [テーマを選ぶ](features/settings.md#テーマを選ぶ) — 「システム」「ライト」「ダーク」から、設定ウィンドウなどの外観を選びます。
- [ログイン時に起動する](features/settings.md#ログイン時に起動する) — Mac にログインしたときに TatakiNote を自動で起動します。
- [メニューバーのアイコンを隠す](features/settings.md#メニューバーのアイコンを隠す) — アイコンを隠したときの開き方と終わらせ方。

## アクセシビリティの許可

- [アクセシビリティの許可](features/accessibility.md) — 挿入と自動表示に要る許可と、許可の手順。許可が無いときの案内は、起動時と確定したときに開きます。
- [許可の状態を確かめる](features/accessibility.md#許可の状態を確かめる) — 設定の「アプリ情報」で、今の許可の状態を見られます。
