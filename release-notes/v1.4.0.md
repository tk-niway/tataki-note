## 新機能

- 設定の「パネル」に「文章の見え方」が加わりました。文字サイズは変えずに、行間・段落の間隔・字間を変えられ、長い文章を読みやすくできます。
- 箇条書きや行頭に空白がある段落が折り返したとき、続きの行の左端を本文の始まりに揃えられるようになりました(「折り返した行の字下げ」)。
- 入力欄の `http://`・`https://` で始まる URL に色が付き、長い URL は先頭にリンクのアイコンを付けて短く畳んで表示されるようになりました。マウスを重ねると全文が吹き出しで出て、カーソルを URL に置くと全文に戻ります。挿入・コピー・書き出し・下書きには URL の全文が入ります。
- `⌘` を押しながら URL をクリックするか、右クリックの「リンクを開く」で、URL を既定のブラウザで開けるようになりました。
- 設定に「カーソル」が加わりました。カーソルの形を「縦線」「ブロック」「下線」から選べるほか、カーソルのある行の背景に色を付けることもできます。

## 注意

- 更新すると、初期値で文字と段落の間がわずかに広がります(字間 7%・段落の間隔 0.25 行)。前と同じ並びに戻したいときは、設定の「文章の見え方」で字間を 0%、段落の間隔を 0 行にしてください。
- URL の畳み表示は、初期値でオンになっています。畳まずに表示したいときは、設定の「URL を畳む」をオフにしてください。オフにしても、`⌘` クリックと右クリックの「リンクを開く」は使えます。
