- ホットキー(既定は `⌥⇧Space`)で入力パネルを開いて文章を書けます。確定キーを押すと、パネルを開いたときに使っていたアプリの入力欄に文章が入ります。確定+送信キーを使うと、文章を入れたあと送信までします。
- パネルでは Enter キーで改行します。日本語の変換や改行の途中で、書きかけの文章をうっかり送信することはありません。パネルを閉じても、書いた文章は下書きとして残ります。
- パネルを開いても、使っていたアプリは前面のままです。文章を入れたあと、コピーしていた内容は元に戻ります。
- 行の入れ替えや複製、行ごとのコピー・切り取り・貼り付けなど、VSCode のような編集のショートカットが使えます。入力欄を選ぶとパネルが自動で出るようにもできます。
- 設定ウィンドウでは、ホットキーと確定キー、パネルを出す位置、フォント・文字サイズ、透明度、パネルの大きさ、テーマ、ログイン時に起動するかどうかを変えられます。

初めて開くときの確認と、アクセシビリティの許可の手順は [README](https://github.com/tk-niway/tataki-note#readme) を見てください。
