TatakiNote の最初のリリースです。AI チャットなどの入力欄で、Enter による誤送信を防ぐための、メニューバーに常駐する macOS アプリです(macOS 14 以降)。

- **パネルで書いて送る**: ホットキー(初期値は `⌥⇧Space`)で入力パネルを開いて書きます。パネルでは Enter は改行なので、変換の確定や改行で書きかけの文章が送られることはありません。
- **挿入と送信**: `⇧⌘↩` で、パネルを開いたときに使っていたアプリの入力欄に文章を入れます。`⌘↩` で、入れたあとに送信まで行います。キーは設定で変えられます。
- **どのアプリでも使える**: ブラウザの AI チャット、Claude や ChatGPT のデスクトップアプリ、Slack や Discord などで使えます。パネルを開いても、使っていたアプリは前面のままです。
- **挿入先が分かる**: タイトルバーのアイコンと入力欄を囲む枠線で、文章が入る場所を確かめられます。パネルを開いたまま別の入力欄をクリックすると、そこに入れ直せます。
- **クリップボードは元に戻る**: 挿入したあと、コピーしていた内容は元に戻ります。
- **書きかけ・下書き・履歴**: 閉じても書きかけは残ります。`⌘S` で下書きに保存し、挿入した文章や書きかけの履歴と一緒に、サイドバー(`⌘B`)から検索して呼び戻せます。
- **ノート**: `⌘E` で書きかけをノートにすると、挿入も送信もしません。送るつもりのないメモに使えます。
- **書き出しと共有**: `⇧⌘S` でテキストファイルに書き出せます。タイトルバーのアイコンから macOS のシェアのメニューで送れます。
- **編集のショートカット**: 行の入れ替え・複製、行ごとのコピー・切り取り・貼り付けなど、VSCode のようなキー操作が使えます。
- **自動で開く**: 選んだアプリの入力欄をクリックしたときに、パネルが自動で開くようにできます。
- **見た目の設定**: パネルを出す位置、フォントと文字サイズ、透明度、既定の大きさ、テーマ、アニメーションを選べます。
- **チュートリアル**: 初めて起動したときに、練習用のチャットで、パネルを開いて書いて送るまでを試せます。
- **公証済み**: Apple の公証を受けているので、ダウンロードした `TatakiNote.app` をそのまま開けます。文章を他のアプリに入れるために、初回にアクセシビリティの許可が要ります。
