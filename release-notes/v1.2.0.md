## 新機能

- **ファイルに書き出す**: `⇧⌘S` で、パネルの文章をテキストファイルとして書き出せます。サイドバーの行を右クリックしても書き出せます。
- **共有する**: タイトルバーの共有のアイコンから、macOS のシェアのメニューで文章を送れます。サイドバーの行を右クリックしても共有できます。
- **書きかけのモード**: 書きかけごとに、`⌘E` で「インサート」と「ノート」を切り替えられます。ノートでは挿入も送信もせず、確定のキーを押すと改行になります。新しい書きかけをどちらで始めるかは、設定の「モード」で選べます。
- **サイドバーをキーボードで操作**: 一覧で `↑` `↓` を押すと、その行の中身がすぐパネルに出ます。`Tab` で「下書き」と「履歴」を切り替え、`⌘⌫` でハイライトしている行を削除します。
- **書きかけは履歴に残る**: 別の下書きや履歴を開いたとき、`⌘N` を押したとき、TatakiNote を終了したときに、書きかけが「履歴」に残ります。
- **履歴に残す件数**: 履歴の上限を 10〜1000 件で選べるようになりました。初期値は 200 件です。
- **Dock のアイコン**: Dock にアイコンを出せるようになりました。Dock のアイコンや Finder・Spotlight から起動すると、パネルが開きます。
- **終了前の確認**: `⌘Q` で終了する前に、確認の窓を出せるようになりました。
- **帯のボタンで確定**: パネルの下の帯の「挿入」「送信」をクリックしても確定できます。

## 改善

- 設定ウィンドウのデザインを新しくしました。項目の名前を「ホットキーとキー操作」「情報」に変え、「自動表示」と「対象のアプリ」は「ホットキーとキー操作」の「自動で開く」に移しました。対象のアプリは、アイコンと名前の入ったチップで並びます。
- 設定の「アニメーション」で、パネルの開閉や保存の演出など、TatakiNote のすべての動きを「システム」「オン」「オフ」から選べるようになりました。
- 下書きに保存すると、文章の写しが保存先へ飛び、「下書きに保存しました」と表示されます。空のパネルで保存や書き出しをしようとすると、パネルが横に揺れて知らせます。
- サイドバーの一覧の行を2段にし、日時と本文の続きも出るようにしました。「下書き」「履歴」の切り替えには件数も出ます。
- 空のパネルは、いつも既定の大きさで開くようにしました。
- 設定ウィンドウを開いても、パネルは開いたままになりました。
- 保存先を選ぶウィンドウなど macOS の標準の画面が、Mac の言語(日本語など)で表示されるようになりました。

## 不具合の修正

- 下書きが空のときに「履歴」へ切り替えると、一覧のフォーカスが外れてしまう問題を直しました。
- ノートの書きかけでパネルを開いたまま別のアプリをクリックしたときに、キー入力がクリックしたアプリに届くようにしました。

## 注意

- 設定でアプリ全体をノートモードにする機能は無くなりました。書きかけごとに `⌘E` で切り替えてください。いつもノートで始めたいときは、設定の「モード」で新しい書きかけのモードを「ノート」にしてください。
- 保存していない文章があるときに出ていた「下書きに保存しますか?」という確認は無くなりました。書きかけは自動で「履歴」に残ります。
- `⌘E` と `⇧⌘S` はパネルで使うキーになりました。確定+挿入キー、確定+送信キー、「パネルを開く・閉じる」にこれらのキーを登録していた場合は、起動したときに初期値に戻ります。必要なら、設定の「ホットキーとキー操作」でもう一度登録してください。
