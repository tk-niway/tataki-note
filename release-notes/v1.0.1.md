## 新機能

- 設定の「フォント」で、Mac 標準のフォントパネルを使えるようになりました。名前で探して書体・太さ・サイズを選ぶと、決定を押さなくても、パネルの入力欄にすぐ反映されます。「システムフォントに戻す」ボタンで元に戻せます。
- 初めて起動したときに、チュートリアルが開くようになりました。AI チャット風の練習用のチャットで、パネルを開いて書き、送るまでの流れを1段階ずつ試せます。設定の「アプリ情報」にある「チュートリアルを開く」から、いつでも開けます。

## 改善

- アクセシビリティの許可の案内が、初めて起動したときに限り、許可をオンにすると「次へ」でチュートリアルに進めるようになりました。
- 確定キーを使った挿入の説明や、パネルの下の帯のキーのヒントが、確定キーの新しい初期値に合わせて変わりました。
- README と利用ガイドの冒頭を、AI チャットでの Enter による誤送信を防ぐアプリという内容で書き直しました。

## 注意

- 確定キー(文章を入れるだけで、送信はしないキー)の初期値が `⇧⌘↩` になりました。以前は登録がなく、確定+送信キー(`⌘↩`)でしか挿入できませんでした。すでに自分でキーを登録している場合は、その設定が使われます。
- 選んだフォントの指定方法が変わりました。更新後にパネルの文字の見た目が変わっていたら、設定の「フォント」でフォントパネルを開いて選び直してください。
